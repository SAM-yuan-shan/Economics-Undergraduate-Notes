# 优先股

## 定义
参见 [[优先股 (Preferred stock)]]

## 简介
优先股股东在分配公司收益和剩余财产方面比普通股具有优先权。

## 主要特征
- **股息固定**：通常股息水平固定
- **优先权**：在分配收益和剩余财产方面优先于普通股
- **无表决权**：在股东大会上通常没有表决权
- **清算优先**：公司破产清算时优先于普通股获得偿付

## 清偿顺序
公司破产清算时的清偿顺序：
```
债权人 → 优先股股东 → 普通股股东
```

## 与普通股的比较
| 特征 | [[普通股]] | 优先股 |
|------|------------|--------|
| 投票权 | 有 | 通常无 |
| 股利 | 浮动 | 固定 |
| 清算顺序 | 最后 | 优先 |
| 风险收益 | 高风险高收益 | 低风险固定收益 |
