# 1 课程：完全掌握价值（基本面）投资分析
## 1.1 课程目标：
全面理解和实际运用价值投资的各项原则，从宏观经济分析到具体的公司估值，从而能够做出明智的投资决策。
## 1.2 模块一：价值投资基础
[[1.2]]
### 1.2.1 价值投资概览
- **你将学会：**
    - 定义什么是价值投资。
    - 理解购买股票即购买公司一部分所有权的核心理念。
    - 掌握公司内在价值来源于其未来现金流的观念。
    - 区分短期市场情绪（投票机）与长期内在价值（称重机）。
### 1.2.2 价值投资分析的前提
- **你将学会：**
    - 理解为什么专业分析被认为能够获得股票的内在价值。
    - 认识到市场价格和内在价值可能存在差距，并且市场最终会纠正这种差距。
## 1.3 模块二：宏观分析（自上而下第一步）
### 1.3.1 宏观分析概述
- **你将学会：**
    - 认识宏观经济因素在投资决策中的重要性。
    - 识别宏观分析的四个主要组成部分：国际宏观分析、宏观经济形势、宏观经济周期和宏观经济政策。
### 1.3.2 国际宏观分析
- **你将学会：**
    - 分析国际**政治因素**（如地缘政治事件、选举、贸易摩擦如中美贸易摩擦、英国脱欧、俄乌战争等）如何影响投资。
    - 评估国际**经济因素**（如全球经济增长、主要经济体如美国和欧盟的利率及政策、汇率）。
        - 解读全球GDP排名和趋势等数据。
        - 理解全球利率变化（如美联储利率）的影响。
    - 评估国际**自然因素**（如气候、地理、自然灾害、疫情如新冠病毒疫情）对经济和市场的影响。
        - 理解疫情等事件如何导致市场波动（如2020年3月美股4次熔断）。
### 1.3.3 国内宏观经济形势
- **你将学会：**
    - 识别和解读关键宏观经济指标：
        - **国内生产总值 (GDP)：** 理解其重要性并分析趋势（如中国GDP增速目标）。
        - **市场利率 (Rate)：** 理解其与估值的关系（如十年期国债收益率与股市市盈率）。
        - **物价指数 (CPI & PPI)：** 区分居民消费价格指数和工业生产者出厂价格指数，并理解它们对通货膨胀和经济健康状况的影响。
        - **采购经理人指数 (PMI)：** 将PMI数据解读为制造业健康状况的指标（读数高于50表示扩张）。
        - **波罗的海干散货指数 (BDI)：** 理解BDI作为全球航运活动和经济健康状况的指标，及其与特定股票（如中远海控）的相关性。
### 1.3.4 宏观经济周期
- **你将学会：**
    - 定义经济周期及其重复发生的特性。
    - 识别和理解四种常见的经济周期及其特点：
        - **基钦周期（3-5年）：** 由存货投资变动驱动，又称存货周期。
        - **朱格拉周期（7-11年）：** 由固定资产投资变动驱动，又称商业周期。
        - **库兹涅茨周期（15-25年）：** 由建筑活动驱动，又称房地产周期。
        - **康德拉季耶夫周期（45-60年）：** 由技术革命和大型基础设施建设驱动。
    - 分析康德拉季耶夫周期的历史案例及其驱动技术（如纺织及蒸汽机、钢铁和铁路、电气和重化工、汽车、电子计算机、信息技术）。
    - 应用**美林投资时钟**，根据通货膨胀和经济增长情况，理解不同资产类别在经济周期的不同阶段（复苏、过热、滞胀、衰退）的表现。
### 1.3.5 宏观经济政策
- **你将学会：**
    - 理解**财政政策**（政府收支）如何影响经济活动，包括税率、政府购买、转移支付等工具（如“积极的财政政策”、减税降费、惠农补贴）。
    - 理解**货币政策**（调节货币供给和利率）如何影响经济，包括存款准备金率、公开市场操作、调整银行利率等工具（如量化宽松、货币从紧）。
## 1.4 模块三：中观行业分析（行业深潜）
### 1.4.1 行业分析概述
- **你将学会：**
    - 理解在投资特定公司之前分析其所在行业的重要性。
    - 识别行业分析的关键组成部分：市场结构、竞争结构、生命周期以及与经济周期的关系。
### 1.4.2 行业分类
- **你将学会：**
    - 熟悉不同的行业分类体系（如证监会行业分类标准、国民经济行业分类GB/T4754-2011）。
### 1.4.3 行业市场结构分析
- **你将学会：**
    - 基于垄断与竞争的关系来定义市场结构，使用行业集中度作为衡量标准。
    - 区分四种主要市场类型及其特征：
        - **完全竞争：** 众多生产者，同质产品，价格接受者，自由进出（如部分农产品）。
        - **垄断竞争：** 众多生产者，差异化产品，对价格有一定控制力（如多数制成品）。
        - **寡头垄断：** 少数主导厂商，对价格和交易有显著控制力，进入壁垒高（如钢铁、汽车、石油）。
        - **完全垄断：** 单一生产者，为最大利润制定价格和产量，进入壁垒极高（如公用事业、部分资源开采）。
### 1.4.4 行业竞争结构分析（波特五力模型）
- **你将学会：**
    - 应用波特五力模型分析一个行业的吸引力和盈利能力：
        - **潜在进入者的威胁：** 新公司进入行业的难易程度。
        - **供给者的议价能力：** 供应商提高价格的能力有多大。
        - **购买者的议价能力：** 客户压低价格的能力有多大。
        - **替代品或服务的威胁：** 客户找到满足其需求替代方式的可能性。
        - **现有竞争者之间的竞争强度：** 当前参与者之间的竞争水平。
    - 理解为什么具有宽“护城河”（强大的定价权，扩张资本投入少）的垄断型或“成瘾性商品”行业（如贵州茅台、可口可乐、云南白药）对巴菲特等投资者具有吸引力。
### 1.4.5 行业生命周期分析
- **你将学会：**
    - 描述行业生命周期的典型阶段：
        - **导入期（初创期）：** 高成本，低销量，负利润或低利润。
        - **成长期：** 销量和利润快速增长，价格可能下降。
        - **成熟期：** 销量达到顶峰，利润率可能因竞争而收窄。
        - **衰退期：** 销量和利润下降。
    - 分析销量、成本、价格和利润在这些阶段通常如何演变。
    - 识别新兴行业（如石墨烯、3D打印、人工智能等，根据所提供图表）所处的生命周期阶段。
### 1.4.6 经济周期与行业分析
- **你将学会：**
    - 根据行业自身发展与国民经济总体周期变动之间关联的密切程度，将行业划分为：
        - **成长型行业：** 表现基本不受经济周期影响，由技术创新和新产品驱动（如高科技、生物技术、新能源、高端制造）。
        - **周期型行业：** 经营状况与经济周期直接相关（如钢铁、有色金属、化工、建材、房地产、家电、煤炭、纺织）。
        - **防守型行业：** 产品需求相对稳定，不受经济周期波动影响（如食品、医药、公用事业、部分日用品如酒类）。
## 1.5 模块四：公司财务分析（核心技能）
### 1.5.1 财报阅读入门
- **你将学会：**
    - 了解获取财务报告的途径（如巨潮资讯网、上交所、深交所）。
    - 识别不同类型的财务报告及其发布时间（一季报、半年报、三季报、年报）。
    - 理解业绩预告和业绩快报的披露规则和时间节点。
### 1.5.2 理解三大财务报表
- **你将学会：**
    - **资产负债表：**
        - 理解其反映特定时点企业的资产、负债及股东权益的存量情况。
        - 掌握核心等式：资产 = 负债 + 所有者权益。
        - 学会从“钱的来源”和“钱的去处”角度解读资产负债表。
        - 运用对比分析法（与同行对比），关注不同项目在总资产中的比重，分析应收/应付/预收/预付账款等科目揭示的公司与上下游地位。
    - **利润表：**
        - 理解其反映企业某一时期经营成果的报表，关注收入、费用、成本的流量情况。
        - 掌握核心公式：营业利润 = 收入 - 支出；利润总额 = 营业利润 + 营业外收支净额。
        - 重点关注核心利润，警惕营业外收支占比较大的公司。
        - 认识到利润表易被操纵的根源——权责发生制，理解其含义和潜在影响。
    - **现金流量表：**
        - 理解其反映企业某一会计期间现金流入流出情况。
        - 区分经营活动、投资活动、筹资活动产生的现金流。
        - 认识到经营活动现金流净额为负通常意味着公司经营困难。
        - 评估投资活动（如跨行业扩张的风险和回报率）。
        - 理解现金流量表中最准确的数字是期初和期末现金总额及其差额，以及经营活动现金流的编制方法（间接法）。
### 1.5.3 关键财务指标分析
- **你将学会计算和解读：**
    - **偿债能力指标：**
        - 流动比率 = 流动资产 / 流动负债 (通常认为2较好)
        - 速动比率 = (流动资产 - 存货) / 流动负债 (通常认为1较好)
        - 资产负债比率 = 负债总额 / 资产总额 (通常认为50%左右较正常)
    - **经营与发展能力指标：**
        - 存货周转率 = 销货成本 / 平均存货
        - 应收账款周转率 = 全年赊销收入 / 平均应收账款
        - 营业利润增长率 = (本期营业利润 - 上期营业利润) / 上期营业利润
        - 税后利润增长率 = (本期税后利润 - 上期税后利润) / 上期税后利润
    - **盈利能力指标：**
        - 主营业务利润率 (或毛利率) = 营业利润 / 主营业务收入 (一般关注30%以上)
        - 净资产收益率 (ROE) = 税后利润 / 公司净资产 (或 股东权益) (一般关注15%以上)
        - 净利润现金含量 = 经营活动现金流量净额 / 净利润
    - **投资收益分析指标：**
        - 每股净资产 = 股东权益 / 总股数
        - 每股收益 (EPS) = 净利润 / 总股数
        - 每股收益 (扣除) = (净利润 - 非经营性损益) / 总股数
        - 市盈率 (P/E) = 每股市场价格 / 每股收益 = 总市值 / 净利润
        - 市净率 (P/B) = 每股市场价格 / 每股净资产 = 总市值 / 净资产
        - 股息率 = 每股派息 / 每股市场价格
## 1.6 模块五：绝对估值法
### 1.6.1 投资的本质与绝对估值
- **你将学会：**
    - 理解投资的三个本质：买股票就是买公司；公司内在价值等于其未来现金流量总和的折现值；市场价格短期看是投票机，长期看是称重机。
### 1.6.2 自由现金流折现模型 (FCFF)
- **你将学会：**
    - 理解自由现金流折现 (DCF) 的基本原理：将资产剩余年限的自由现金流以适当利率折现。
    - 自由现金流 (F) 的概念：企业经营活动现金流入减去维持运营的资本投入后剩余的现金。
        - 估算方法：“经营现金流净额” - “购建固定资产、无形资产和其他长期资产支付的现金”。
    - 折现率 (r) 的确定：无风险收益率 + 风险补偿 (可参考2倍无风险收益率或WACC)。
    - 两段式自由现金流估值模型：
        - $V = \frac{F_{1}}{(1+r)} + \frac{F_{2}}{(1+r)^{2}} + \frac{F_{3}}{(1+r)^{3}} + \frac{\frac{F_{3}(1+g)}{r-g}}{(1+r)^{3}}$
        - 理解前段（可准确估计的3-5年）和后段（永续增长）的现金流折现。
        - 永续增长率 (g) 的假设 (如 $g = r_f$，无风险收益率)。
    - 分析自由现金流估值案例（如茅台）。
### 1.6.3 股利折现模型 (DDM)
- **你将学会：**
    - 理解股利折现模型的基本公式：$P = \frac{D_{1}}{1+r} + \frac{D_{2}}{(1+r)^{2}} + ... + \frac{D_{n}}{(1+r)^{n}} + ...$
    - 戈登增长模型 (股利固定比例增长)：
        - $P = \frac{D_{0}(1+g)}{r-g} = \frac{D_{1}}{r-g}$
        - 其中 $D_0$ 为初始股利，$D_1$ 为下一期股利，g为股利增长率，r为折现率。
### 1.6.4 股利增长率的估算
- **你将学会：**
    - 估算股利增长率 (g) 的方法：
        - $g = b \times ROE$ (其中 b 为公司留存收益比例，ROE为净资产收益率)
        - $g = \sqrt[n]{\text{期末股利派发}/\text{期初股利派发}} - 1$ (基于历史股利派发)
### 1.6.5 股利分配对股票价值的影响
- **你将学会：**
    - 理解现金分红的意义和证监会的导向。
    - 分析不同类型和发展阶段公司现金分红的适宜性（成熟型公司 vs 高速发展型公司）。
    - 通过数学推导理解股利政策与股票价值的关系：
        - 当 $ROE > r$ 时，留存收益比例 $b$ 越大，股票价值 $P$ 越大（公司能用留存的钱赚取更高回报）。
        - 当 $ROE < r$ 时，留存收益比例 $b$ 越大，股票价值 $P$ 越小（不如分红给股东自行投资）。
## 1.7 模块六：相对估值法（可比公司估值法）
### 1.7.1 市盈率 (P/E) 估值法
- **你将学会：**
    - 市盈率的计算：P/E = P/EPS = 公司市值 / 年净利润总额。
    - 应用市盈率进行估值：股票价格 = 合理的市盈率水平 × 待估股票的EPS。
    - 理解同类公司市盈率应接近的逻辑及套利机会。
    - 如何参考市场、行业平均、类似公司市盈率水平来确定合理的市盈率。
### 1.7.2 对市盈率的辩证认识
- **你将学会：**
    - 认识到不同行业、不同公司的市盈率不能简单对比。
    - 理解市盈率不适用于强周期性行业（如石化、煤炭、钢铁）及净利润为负的企业。
    - 从戈登模型推导市盈率公式： $P/E = \frac{(1-b)}{r-ROE \times b}$
    - 理解预期的合理市盈率水平取决于收益留存比率 (b)、必要报酬率 (r) 和净资产收益率 (ROE)。
### 1.7.3 成长股估值指标PEG
- **你将学会：**
    - PEG指标的计算：$PEG = \frac{PE}{\text{企业未来三年每股收益复合增长率} \times 100}$
    - PEG指标的解读：
        - PEG < 1：说明公司价值可能被低估。
        - PEG > 1：说明公司价值可能被高估。
    - 分析PEG估值案例（如中芯国际）。
### 1.7.4 其他相对估值方法
- **你将学会：**
    - **市净率 (P/B)：** $P/B = \text{公司市值} / \text{净资产}$
        - 适用于重资产、净资产为正的公司（如金融机构、银行）。
    - **市销率 (P/S)：** $P/S = \text{公司市值} / \text{销售收入}$
        - 适用于发展到一定阶段有稳定收入的公司（如互联网、通信设备、制药、公共事业）。
    - **公司价值倍数 (EV/EBITDA)：** $EV/EBITDA = \text{公司价值} / \text{息税折旧摊销前利润}$
        - EV (公司价值) = 公司市值 + 总负债 - 总现金
        - EBITDA = 净利润 + 所得税 + 利息 + 折旧 + 摊销
        - 适用于资本密集型企业（如电信、化工、航空）。
## 1.8 模块七：综合应用与投资实践
### 1.8.1 价值投资分析流程回顾
- **你将学会：**
    - 再次梳理价值投资的分析框架：宏观经济 -> 行业分析 -> 公司分析。
### 1.8.2 建立自选股股票池
- **你将学会：**
    - **价值股筛选标准：**
        - 业绩为王（年净利润 > 10亿，连续三年营收和净利增速 > 10%）。
        - 分红率 > 40%。
        - 行业龙头。
        - ROE > 10%，毛利率 > 20%，资产负债率 < 50%。
        - 经营性现金流为正。
        - 管理层靠谱。
    - **成长股筛选标准：**
        - 业绩为王（连续三年营收增速 > 30%，净利增速 > 25%）。
        - 市值200亿以内。
        - 行业龙头。
        - ROE > 15%，毛利率 > 30%，资产负债率 < 50%。
        - 经营性现金流为正。
        - PEG < 1。
        - 管理层靠谱。
### 1.8.3 价值投资与技术分析的结合
- **你将学会：**
    - 理解技术分析的优势（分析投资心理和行为，适合短期择时）。
