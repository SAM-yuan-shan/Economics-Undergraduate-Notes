## 每股收益无差别点分析 (第六章第七题) (10:52:23 - 11:01:11)

### 核心概念与步骤

计算和运用每股收益无差别点（EPS Indifference Point）进行筹资决策，主要分两步：

1.  **计算每股收益无差别点 ($\text{EBIT}^*$)**: (10:52:54)
    * 该点是指在该息税前利润（EBIT）水平上，不同筹资方案下的每股收益（EPS）相等。
    * 通过建立等式：$\text{EPS}_{\text{方案1}} = \text{EPS}_{\text{方案2}}$ 来求解 $\text{EBIT}^*$。(10:53:02)
    * EPS通用公式：(10:53:49)
        $$\text{EPS} = \frac{(\text{EBIT} - I) \times (1 - T) - \text{PD}}{N}$$
        其中：
        * `EBIT`: 息税前利润
        * `I`: 利息费用
        * `T`: 所得税税率
        * `PD`: 优先股股息 (本题不涉及，公式简化为 $\frac{(\text{EBIT} - I) \times (1 - T)}{N}$) (10:53:58)
        * `N`: 普通股股数

2.  **比较与决策**: (10:53:18)
    * 将计算出的 $\text{EBIT}^*$ 与企业预期的息税前利润（Expected EBIT）进行比较。(10:53:27)
    * 如果 $\text{Expected EBIT} > \text{EBIT}^*$：选择债务筹资方案（或杠杆较高的方案）。(10:53:34)
    * 如果 $\text{Expected EBIT} < \text{EBIT}^*$：选择股权筹资方案（或杠杆较低的方案）。
    * 口诀：“左股右债” - 以 $\text{EBIT}^*$ 为分界点，预期EBIT在右侧（更大）选债，在左侧（更小）选股。(10:59:08)

### 案例分析：第六章第七题

#### 题目背景 (10:54:08)

* **2005年状况**:
    * 长期资本总额：1亿元
        * 普通股：6000万元
        * 长期债务：4000万元 (利率 10%) (10:54:16, 10:54:25)
    * 普通股股数：240万股 (10:54:08)
    * 资本结构：负债/权益 = 4000万/6000万 = 4/6 (10:54:16)
* **2006年计划**:
    * 长期资本总额增加至：1.2亿元 (追加投资2000万元) (10:54:35)
    * 预计2006年息税前利润 (EBIT)：2000万元 (10:55:07)
    * 所得税税率 (T)：25% (根据后续 `(1-25%)` 或 `一减百分之二十五` 推断) (10:57:09)

* **追加投资方案**: (10:54:42)
    1.  **方案一 (发债)**: 全部发行公司债券，筹集2000万元，债券票面利率 12%。(10:54:46)
        * 新增利息 = 2000万元 * 12% = 240万元 (10:54:50)
    2.  **方案二 (发股)**: 全部增发普通股，发行80万股。(10:54:59)

#### 第一问：测算两个追加投资方案下的每股收益无差别点的息税前利润 ($\text{EBIT}^*$) 及该点的普通股每股收益 ($\text{EPS}^*$) (10:52:46)

1.  **列出各方案EPS表达式**: (10:55:15)

    * **方案一 (发债)**:
        * 原有债务利息 $I_0$ = 4000万元 * 10% = 400万元 (10:55:31, 10:55:39)
        * 新增债务利息 $I_1$ = 2000万元 * 12% = 240万元 (10:55:48)
        * 总利息 $I_{\text{方案1}}$ = 400 + 240 = 640万元 (10:55:48)
        * 普通股股数 $N_1$ = 240万股 (10:55:55)
        $$\text{EPS}_1 = \frac{(\text{EBIT}^* - 640) \times (1 - 25\%)}{240}$$
        (分子为归属于普通股的净利润，分母为普通股总股数)

    * **方案二 (发股)**: (10:56:03)
        * 总利息 $I_{\text{方案2}}$ = 400万元 (仅原有债务利息，因为方案二是发股，不产生新利息) (10:56:10)
        * 普通股股数 $N_2$ = 240万股 (原有) + 80万股 (新增) = 320万股 (10:56:28)
        $$\text{EPS}_2 = \frac{(\text{EBIT}^* - 400) \times (1 - 25\%)}{320}$$

2.  **令 $\text{EPS}_1 = \text{EPS}_2$ 求解 $\text{EBIT}^*$**: (10:56:36)
    $$\frac{(\text{EBIT}^* - 640) \times (1 - 25\%)}{240} = \frac{(\text{EBIT}^* - 400) \times (1 - 25\%)}{320}$$
    由于 $(1 - 25\%)$ 在等式两边可以约去：(10:57:09)
    $$\frac{\text{EBIT}^* - 640}{240} = \frac{\text{EBIT}^* - 400}{320}$$
    交叉相乘：(10:57:17)
    $$320 \times (\text{EBIT}^* - 640) = 240 \times (\text{EBIT}^* - 400)$$
    $$320 \text{EBIT}^* - 320 \times 640 = 240 \text{EBIT}^* - 240 \times 400$$
    (10:57:27: $320 \times \text{EBIT}^* - (640 \times 320) = 240 \times \text{EBIT}^* - (400 \times 240)$ )
    $$320 \text{EBIT}^* - 204800 = 240 \text{EBIT}^* - 96000$$
    $$(320 - 240) \text{EBIT}^* = 204800 - 96000$$
    $$80 \text{EBIT}^* = 108800$$
    $$\text{EBIT}^* = \frac{108800}{80} = 1360 \text{万元}$$
    (讲话中为1360，单位应为万元) (10:58:00)

3.  **计算在 $\text{EBIT}^* = 1360$万元时的每股收益 $\text{EPS}^*$**: (10:58:08)
    代入任一方案的EPS公式，例如方案一 (讲话中选择代入方案一，但强调代入任一方案结果相同): (10:58:16, 10:58:30)
    $$\text{EPS}^* = \frac{(1360 - 640) \times (1 - 0.25)}{240} = \frac{720 \times 0.75}{240} = \frac{540}{240} = 2.25 \text{元/股}$$
    (讲话中为2.25元/股) (10:58:38)

4.  **利用EBIT\*进行初步决策** (作为第一问的完整步骤之一): (10:58:54 - 10:59:25)
    * 已算出的每股收益无差别点 $\text{EBIT}^* = 1360$万元。
    * 题目给出的预计2006年息税前利润 Expected EBIT = 2000万元。(10:59:00)
    * 比较：Expected EBIT (2000万元) > $\text{EBIT}^*$ (1360万元)。(10:59:08)
    * 结论：应选择债务筹资方案（方案一），因为预期EBIT大于无差别点EBIT，属于“右债”区域。(10:59:16, 10:59:25)

#### 第二问：计算追加投资方案下2006年的普通股每股收益，并做出选择 (10:52:46, 实际解答在 10:59:25 后)

使用预计的 EBIT = 2000万元，分别计算两个方案的EPS。注意这里的EBIT是预期的2000万，而不是第一问算出的$\text{EBIT}^*$。(10:59:40)

1.  **方案一 (发债) 的EPS**: (10:59:40)
    * EBIT = 2000万元
    * 总利息 $I_{\text{方案1}}$ = 640万元 (原有400万 + 新增240万) (10:59:56)
    * 普通股股数 $N_1$ = 240万股
    $$\text{EPS}_1 = \frac{(2000 - 640) \times (1 - 0.25)}{240} = \frac{1360 \times 0.75}{240} = \frac{1020}{240} = 4.25 \text{元/股}$$
    (讲话中为4.25元/股) (11:00:04)

2.  **方案二 (发股) 的EPS**: (11:00:04)
    * EBIT = 2000万元
    * 总利息 $I_{\text{方案2}}$ = 400万元 (仅原有债务利息)
    * 普通股股数 $N_2$ = 320万股 (原有240万 + 新增80万) (11:00:12)
    $$\text{EPS}_2 = \frac{(2000 - 400) \times (1 - 0.25)}{320} = \frac{1600 \times 0.75}{320} = \frac{1200}{320} = 3.75 \text{元/股}$$
    (讲话中为3.75元/股) (11:00:20)

3.  **决策**: (11:00:20)
    * 比较：$\text{EPS}_1 (4.25\text{元/股}) > \text{EPS}_2 (3.75\text{元/股})$。
    * 结论：选择方案一 (发债)，因为其预期每股收益更高。(11:00:28)

### 总结与对比 (11:00:36)

* 第一问通过计算无差别点$\text{EBIT}^*$，并与预期EBIT比较，得出应选择**方案一 (偏债务型)**。(11:00:36)
* 第二问直接计算在预期EBIT下各方案的EPS，比较大小，同样得出应选择**方案一 (发债的筹资方案)**。(11:00:44)
* 两种方法结论一致，都指向方案一，说明了分析的有效性。无差别点法是考试中更常考的方法，计算量相对大一些，需要理清思路。(11:00:51, 11:01:07)
