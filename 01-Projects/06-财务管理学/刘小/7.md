# 资金需求量预测

#财务管理 #资金预测

## 核心概念：基期与预测期

- **基期 (Base Period)**：已知财务数据的年份，作为预测的基础。
  - 例子：视频中提到的 "2022年是基期"。
- **预测期 (Forecast Period / 限期)**：需要预测资金需求的未来年份。
  - 例子：视频中提到的 "2023年是叫限期"。

## 一、资金需求量的基本逻辑 (甜甜圈比喻)

### 1. 基期情况 (2022年)
- **目标与需求**：
  - 目标：体重增长到100斤。
  - 实现方式：需要吃10个甜甜圈。
  - "假设我在2022年，我的目标是长到100斤，那如果说我要长到100斤呢，我现在必须要吃十个甜甜圈。"
- **资产**：
  - 假设：甜甜圈1元/个。
  - 所需资产：10个甜甜圈 = 10元。
  - "一旦我买了十个甜甜圈，那这十个甜甜圈它是不是属于我的一个资产，所以那我现在就是需要的资产是多少呢，是十个甜甜圈，是总共是十块钱。"
- **负债 (赊账)**：
  - 赊账比例：30%。
  - 负债金额：10元 * 30% = 3元 (对应3个甜甜圈)。
  - "十块钱我掏不出来这么多钱，那我就赊账30%，也就是说我现在有30%，是暂时不去付款的...这三元是什么呢，就是我们的负债。"
- **资金需求量**：
  - 计算：所需资产 - 负债 = 10元 - 3元 = 7元。
  - "去除这一部分负债，我现在还需要支付多少钱，是不是还需要支付10-3=7元，那这七元就是我现在的一需要的一个资金量。"
  - 公式：$$资金需求量_{基期} = 资产_{基期} - 负债_{基期}$$

### 2. 预测期情况 (2023年)
- **目标与需求**：
  - 目标：体重增长到150斤。
  - "2023年是不是限期，我现在需要想要涨到150斤啊。"
- **增长率计算**：
  - 体重增长率：(150斤 - 100斤) / 100斤 = 50%。
  - "假设我们这个增长率它是保持不变的，那这个增长率是多少呢，是不是50%计算出来。"
- **资产 (按比例增长)**：
  - 所需甜甜圈：10个 * (1 + 50%) = 15个。
  - 所需资产：15个甜甜圈 = 15元。
  - "我原来是需要十个甜甜圈，现在是不是就需要10 \times (1 + 50\%)个甜甜圈，那这样同样也可以算出来是15个甜甜圈。"
- **负债 (按比例增长)**：
  - 赊账比例仍为30%。
  - 负债金额：15元 * 30% = 4.5元。
  - "同样的我现在仍然是掏不出来，15块钱...我是赊账30%，那这样的话我就是需要...负债4.5个甜甜圈，也就是4.5元。"
- **预测期总资金需求**：
  - 计算：预测期资产 - 预测期负债 = 15元 - 4.5元 = 10.5元。
  - "2023年我的一个资金需要量是多少呢，是不是就拿资产减去负债，也就是10.5元。"

### 3. 预测期新增资金需求量
- **考虑基期已投入**：预测期的资金需求是在基期基础上的增量。
  - 新增资金需求量 = 预测期总资金需求 - 基期已投入资金 = 10.5元 - 7元 = 3.5元。
  - "2023年的资金需要量，是不是要拿这个10.5减去，2022年支付过的这个七元对吧，所以呢2023年的资金需要量，就是10.5-7=3.5。"

### 4. 从增量角度计算资金需求量
- **资产增量 ($\Delta$资产)**：
  - 计算：预测期资产 - 基期资产 = 15元 - 10元 = 5元。
  - 或：基期资产 * 增长率 = 10元 * 50% = 5元。
  - "德尔塔资产，也就是2023年的资产，减去2022年的资产，也就是资产的一个增量，资产的增量是多少，是不是15-5=5元。" (应为15-10=5)
- **负债增量 ($\Delta$负债)**：
  - 计算：预测期负债 - 基期负债 = 4.5元 - 3元 = 1.5元。
  - 或：基期负债 * 增长率 = 3元 * 50% = 1.5元。
  - "而负债的增量是多少呢，是不是1.5元...是不是就可以拿G7，三元乘以增长率50%等于1.5元。"
- **资金需求量公式**：
  - $$资金需求量 = \Delta 资产 - \Delta 负债$$
  - 计算：5元 - 1.5元 = 3.5元。
  - "所以呢我们资金的需求量，它的公式是什么呢，其实就是拿资产的一个变化量，减去负债的一个变化量啊。"
  - 进一步：$$资金需求量 = (基期资产 \times 增长率) - (基期负债 \times 增长率)$$ (假设增长率一致)

## 二、销售百分比法 (Sales Percentage Method)

### 1. 核心假设
- **经营性资产和经营性负债与销售收入（营业收入）之间存在稳定的百分比关系。**
  - "假定的是我们资产和负债，它与收入的百分比均与基期保持不变。"
  - "经营性的资产A和经营性的负债B与营业收入之间，存在着稳定的百分比方关系啊，经营性是什么意思，就是说这个资产和负债是用于生产经营的。"

### 2. 概念转换 (从甜甜圈到财务报表)
- **基期 (2022年) - 财务数据**
  - 目标收入：1000元。
  - "现在就转换到我们财务管理的思维里面，就是我想要获得一个收入是1000元。"
  - 资产：500元。
  - 负债 (按收入比例假设或按资产比例，视频中先按资产后明确按收入)：
    - 资产占收入百分比：$500 / 1000 = 50\%$
    - 负债 (按资产的30%模拟)：$500 \times 30\% = 150$元。
    - 负债占收入百分比：$150 / 1000 = 15\%$
    - "收入是1000，资产是500，负债是多少，负债是150...资产占收入的一个销售百分比是多少呢，是不是拿500÷1000等于50%，而负债占收入的一个销售百分比是多少，是不是150÷1000等于15%啊。"

- **预测期 (2023年) - 财务数据**
  - 目标收入：2000元 (增长100%)。
  - "假设我2023年需要2000块钱的收入。"
  - 资产 (按50%销售收入比例)：$2000 \times 50\% = 1000$元。
  - 负债 (按15%销售收入比例)：$2000 \times 15\% = 300$元。
  - "资产占收入的一个销售百分比，是不是还是50%，而负债占销销售收入的百分比，是不是还是15%，也就是说从2022年到2023年，我们发现资产和负债，它占收入的一个销售百分比是保持不变的。"

### 3. 资金的来源
- **内部融资 (Internal Financing)**：主要来自留存收益。
  - 计算：$$内部融资额 = 净利润 \times 利润留存率$$
  - 进一步分解：$$内部融资额 = 预计销售收入 \times 销售净利率 \times 利润留存率$$
    - **销售净利率**：净利润 / 销售收入。
      - "这个净利润除以销售收入，它其实就是我们的这个销售净利率...销售净利率它是不是相当于某某某某绿...所以这是一个什么绿呢，是一个母子绿。"
      - 例子："假设我今年获得一个净利润1000元...我能全部拿来去呃，筹资吗，是不是不可以，我是不是要看一个留存...所以这个就叫利润留存率啊。"
- **外部融资 (External Financing)**：债务筹资、股权筹资、混合筹资。
  - "外部筹资呢是分为债务筹资，股权筹资，混合筹资。"

### 4. 销售百分比法计算步骤
**目标：计算外部融资需求量 (EFN - External Financing Needed)**

**Step 1: 计算资金需求总量 (Total Funding Needs)**
- 公式：$$资金需求量 = \Delta 经营性资产 - \Delta 经营性负债$$
  - $\Delta$经营性资产 = 预计销售收入增量 $\times$ (基期经营性资产 / 基期销售收入)
    = 基期经营性资产 $\times$ 销售增长率 (g)
  - $\Delta$经营性负债 = 预计销售收入增量 $\times$ (基期经营性负债 / 基期销售收入)
    = 基期经营性负债 $\times$ 销售增长率 (g)
- "第一个我们会知道资产资求，资金的需求量，它是等于增加的资产减去增加的负债的好。"
- **注意**：仅包括随销售收入变动的经营性项目。资产负债表中标记为 'N' (与销售无关系 Non-sensitive) 的项目不参与此部分的计算。
  - "这个N是什么意思，N就代表它这个项目啊，它与这个销售是无关系，没有关系，那没有关系，是不是就不是经营性的。"

**Step 2: 计算内部融资额 (增加的留存收益)**
- 公式：$$内部融资额 = 预计的销售收入 \times 销售净利率 \times 利润留存率$$
- "减去增加的留存收益，增加留存收益怎么算呢，就等于预计的销售收入乘以销售净利率，乘以利润留存率啊。"

**Step 3: 计算外部融资需求量 (EFN)**
- 公式：$$外部融资需求量(EFN) = 资金需求总量 - 内部融资额$$
- "外部筹资是不是就等于资金需求量，减去内部的一个筹资，对不对。"

### 5. 例题解析
- **背景信息**：
  - 公司2015年 (基期) 销售额：10,000 万元。
  - 销售净利率：10%。
  - 利润留存率：40%。
  - 2016年 (预测期) 销售预计增长 (g)：20%。
  - 销售净利率和利润留存率保持不变。
  - "某公司于2015年12月31日，的简要资产负债表...假定公司2015年销售额为一万万元，销售净利率为10%，利润留存率为40%，2016年销售预计增长20%。"

- **从资产负债表识别经营性项目**：
  - 2015年总资产：8000 万元。
  - 固定资产 (N)：3000 万元 (与销售无关)。
  - **2015年经营性资产**：8000 - 3000 = 5000 万元。
    - "带N的，是不是不用管它，所以我们这里的8000是不是要减去一个3000，经营性资产是不是五千。"
  - **2015年经营性负债** (视频中直接给出)：1500 万元 (例如应付账款等随销售变动的负债，短期借款(N)不计入)。
    - "负债中是不是这个带N的，这一部分与销售无关的，就不用管它，所以我们的负债是不是只有1500。"

- **计算过程**：
  1.  **资金需求总量**：
      - $\Delta$经营性资产 = $5000 \times 20\% = 1000$ 万元。
      - $\Delta$经营性负债 = $1500 \times 20\% = 300$ 万元。
      - 资金需求总量 = $1000 - 300 = 700$ 万元。
      - "经营性资产是不是五千五千，它的一个增长率是多少，是20%，所以5000乘以20%至德尔塔资产，那负债呢...我们的负债是不是只有1500，1500，他是不是要乘以一个GG是20%，最后算出来资金的需求量是700元。"

  2.  **内部融资额 (增加的留存收益)**：
      - 预计2016年销售收入 = $10000 \times (1 + 20\%) = 12000$ 万元。
      - 内部融资额 = $12000 \times 10\% \times 40\% = 12000 \times 0.10 \times 0.40 = 480$ 万元。
      - "首先预测期的销售收入，也就是2016年的销售收入...是不是2016年的一个销售收入，就1万×(1加20%)...再乘以销售净利率...再乘以利润留存率...40%。"

  3.  **外部融资需求量 (EFN)**：
      - EFN = $700 - 480 = 220$ 万元。
      - "那这样呢我们就最后算出来，外部融资的需求量是220元。"

## 三、总结
- 重点讲解了**销售百分比法** (也称营业收入百分比法)。
- 该方法基于资产、负债与销售收入间的稳定百分比关系。
- 区分经营性项目和非经营性项目至关重要。
- 外部融资需求量 = (经营性资产增加 - 经营性负债增加) - 内部融资增加额。
