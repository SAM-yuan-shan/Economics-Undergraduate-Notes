# 资本资产定价模型与证券市场线总结

## 资本资产定价模型 (CAPM)

### 核心思想
投资的必要收益率由两部分组成：
1.  **无风险收益率 (Risk-Free Rate, RF)**：保底收入，例如银行存款或国库券的收益率。
2.  **风险收益率 (Risk Premium)**：对承担风险的补偿，特指**系统风险**（不可分散风险）的补偿。

### 公式
$$R_I = R_F + \beta_I \times (R_M - R_F)$$

其中：
-   $R_I$：单项资产的必要收益率 (Required Rate of Return for asset I)
-   $R_F$：无风险收益率 (Risk-Free Rate)
    -   也常被称为：**国库券的收益率**
-   $\beta_I$：贝塔系数 (Beta Coefficient for asset I)，衡量该资产相对于市场组合的系统风险。
    -   $\beta = \frac{\text{某一项证券的风险}}{\text{市场上的风险}}$
-   $R_M$：市场组合的整体收益率 (Market Rate of Return)
    -   也常被称为：**所有股票的平均报酬率** 或 **所有证券的平均报酬率**
-   $(R_M - R_F)$：市场风险溢价 (Market Risk Premium)，即市场组合的风险收益率。

**例子**：
-   句子：假设我现在要进行一项投资，我肯定就会要求有一定的收益，这个收益率叫必要收益率。
-   单词：必要收益率、无风险收益率、风险收益率、贝塔系数。

### 市场均衡
在市场均衡的情况下：
期望报酬率 = 必要报酬率
此时，仍可使用资本资产定价模型计算期望报酬率。

## 证券市场线 (Security Market Line - SML)

### 定义
证券市场线 (SML) 表示**必要报酬率 ($R_I$)** 与 **不可分散风险 ($\beta$系数)** 之间的线性关系。

**区别于资本市场线 (CML)**：
-   **CML**：表示收益率 ($R$) 与 **整体风险 ($\sigma$ 标准差)** 之间的关系。
-   **SML**：表示收益率 ($R_I$) 与 **不可分散风险 ($\beta$)** 之间的关系。

### SML方程与图形
SML的方程即为CAPM模型方程：
$$R_I = R_F + \beta_I \times (R_M - R_F)$$
可以将其视为一个线性函数 $Y = b + aX$：
-   $Y$ (纵坐标)：必要报酬率 ($R_I$)
-   $X$ (横坐标)：贝塔系数 ($\beta_I$)
-   $b$ (截距)：无风险报酬率 ($R_F$)
-   $a$ (斜率)：市场风险溢价 ($R_M - R_F$)

**图形特征**：
-   横坐标：$\beta$
-   纵坐标：$R_I$
-   截距 (与纵轴交点)：$R_F$
-   斜率：$(R_M - R_F)$

**例子**：
-   句子：证券市场线它讲述的是这个必要报酬率，与不可分散风险贝塔系数之间的关系。
-   单词：截距、斜率。

### 关于SML的关键知识点

1.  **斜率和截距**：
    -   截距是 $R_F$。
    -   斜率是 $(R_M - R_F)$。

2.  **$\beta$系数与必要报酬率的关系**：
    -   风险报酬率 = $\beta \times (R_M - R_F)$
    -   当 $\beta$ 越大，风险报酬率越大。
    -   在 $R_F$ 不变的情况下，风险报酬率变大，则 $R_I$ (必要报酬率) 也会变大。
    -   **结论**：$\beta$ 增大时，$R_I$ 随之增大。
    -   例子：
        -   句子：当贝塔系数增大的时候，那我们这个必要报酬率也会随之增大。
        -   单词：风险报酬率。

3.  **通货膨胀的影响**：
    -   通货膨胀导致钱不值钱，无风险利率 ($R_F$) 会上升。
        -   例子：原来我们买肉需要花十块钱一斤，现在变成了十五块钱一斤。
        -   银行贷款利率会因此提升。例如，银行借钱利率从7%提升到10%。
    -   $R_F$ 上升导致SML的截距上移。
    -   SML发生**向上平行移动** (斜率不变)。
    -   例子：
        -   句子：当钱不值钱的时候呢，无风险利率就会上升。
        -   单词：通货膨胀。

4.  **直线陡峭程度与投资者风险规避**：
    -   SML越陡峭，斜率 $(R_M - R_F)$ 越高。
    -   斜率越高，意味着风险补偿率 ($\beta \times (R_M - R_F)$) 变高。
    -   风险补偿率变高，说明投资者对相同风险要求的补偿（回报）变高。
    -   在相同的期望报酬率水平下，更陡峭的SML对应的$\beta$值更小。
    -   **结论**：直线越陡峭，投资者越规避风险。
    -   例子：
        -   句子：直线越陡峭，斜率就越高。当要求的回报越高，投资者就越规避风险。
        -   单词：陡峭、风险补偿率、规避风险。

## 第二章 风险与报酬的习题讲解

### [[习题八]]：中原公司与南方公司股票投资决策

**已知**：经济情况（繁荣、一般、衰退）的概率分布及对应报酬率。

**问题**：
1.  分别计算中原公司和南方公司股票的期望报酬率 (E(R))、标准差 ($\sigma$) 和离散系数 (CV)。
2.  判断应投资于哪个公司。

**计算方法**：
1.  **期望报酬率 (E(R))**：加权平均法
    $$E(R) = \sum_{i=1}^{n} (P_i \times R_i)$$
    其中 $P_i$ 是概率，$R_i$ 是对应报酬率。
    -   例子（中原公司）：
        $E(R)_{\text{中原}} = (0.3 \times 40\%) + (0.5 \times 20\%) + (0.2 \times 0\%) = 22\%$
2.  **标准差 ($\sigma$)**：
    -   先计算方差 ($\sigma^2$)：
        $$\sigma^2 = \sum_{i=1}^{n} P_i \times (R_i - E(R))^2$$
    -   例子（中原公司，E(R)=22%）：
        $\sigma^2_{\text{中原}} = 0.3 \times (40\% - 22\%)^2 + 0.5 \times (20\% - 22\%)^2 + 0.2 \times (0\% - 22\%)^2$
    -   标准差：
        $$\sigma = \sqrt{\sigma^2}$$
3.  **离散系数 (CV)**：
    $$CV = \frac{\sigma}{E(R)}$$

**投资决策标准**：
-   当期望报酬率不同时，比较**离散系数 (CV)**。
-   CV越大，风险越大。
-   选择**离散系数较小**的公司进行投资。
-   例子：
    -   句子：当期望报酬率不同的时候，我们是不是比较这个离散系数的大小啊。
    -   单词：期望报酬率、标准差、离散系数。

### [[习题九]]：计算不同证券的必要报酬率

**已知**：
-   A, B, C, D 四种证券的 $\beta$ 系数分别为 1.5, 1.0, 0.4, 0.5。
-   无风险报酬率 ($R_F$) = 8%。
-   市场组合报酬率 ($R_M$) = 14%。

**问题**：求各证券的必要报酬率 ($R_A, R_B, R_C, R_D$)。

**计算方法**：使用CAPM公式：$R_I = R_F + \beta_I \times (R_M - R_F)$
-   市场风险溢价 ($R_M - R_F$) = $14\% - 8\% = 6\%$
-   例子（A公司）：
    $R_A = 8\% + 1.5 \times (14\% - 8\%) = 8\% + 1.5 \times 6\% = 8\% + 9\% = 17\%$
-   B公司：$R_B = 8\% + 1.0 \times 6\% = 14\%$
-   C公司：$R_C = 8\% + 0.4 \times 6\% = 10.4\%$
-   D公司：$R_D = 8\% + 0.5 \times 6\% = 11\%$
-   例子：
    -   句子：那我们就代入公式ABCD，我们直接这个它们不同的不就是贝塔系数吗。
    -   单词：无风险报酬率、市场组合报酬率。

### [[习题十]]：市场风险报酬率与投资决策

**已知**：
-   国库券利息率 ($R_F$) = 5%。
-   市场证券组合的报酬率 ($R_M$) = 13%。

**问题**：
1.  计算市场风险报酬率。当 $\beta = 1.50$ 时，必要报酬率应为多少？
2.  若一项投资计划 $\beta = 0.8$，期望报酬率 = 11%，是否应当投资？
3.  若某股票必要报酬率 = 12.2%，其 $\beta$ 值是多少？

**计算与解答**：
1.  **市场风险报酬率** ($R_M - R_F$)：
    $R_M - R_F = 13\% - 5\% = 8\%$
    当 $\beta = 1.50$ 时，必要报酬率 ($R_I$):
    $R_I = R_F + \beta \times (R_M - R_F) = 5\% + 1.5 \times (13\% - 5\%) = 5\% + 1.5 \times 8\% = 5\% + 12\% = 17\%$
    -   例子：
        -   句子：国库券的利率，是不是就是RF，RF等于多少5%。
        -   单词：国库券利息率、市场风险报酬率。

2.  **投资决策**：
    -   计划的 $\beta = 0.8$。
    -   计算该计划的必要报酬率 ($R_{\text{必要}}$)：
        $R_{\text{必要}} = 5\% + 0.8 \times (13\% - 5\%) = 5\% + 0.8 \times 8\% = 5\% + 6.4\% = 11.4\%$
    -   该计划的期望报酬率 ($R_{\text{期望}}$) = 11%。
    -   比较：$R_{\text{期望}} (11\%) < R_{\text{必要}} (11.4\%)$
    -   **结论**：不应当进行投资，因为期望报酬率低于最低要求的报酬率。
    -   例子：
        -   句子：因为你对这项投资的一个最高期望值，才是11%，而这项投资本身它的一个最低的一个报酬率，就是多少了，就是11.4。
        -   单词：期望报酬率、必要报酬率。

3.  **计算 $\beta$ 值**：
    -   已知必要报酬率 ($R_I$) = 12.2%。
    -   $12.2\% = R_F + \beta \times (R_M - R_F)$
    -   $12.2\% = 5\% + \beta \times (13\% - 5\%)$
    -   $12.2\% = 5\% + \beta \times 8\%$
    -   $12.2\% - 5\% = \beta \times 8\%$
    -   $7.2\% = \beta \times 8\%$
    -   $$\beta = \frac{7.2\%}{8\%} = 0.9$$
    -   例子：
        -   句子：如果某只股票的必要报酬率为12.2%，其贝塔值为多少。
        -   单词：贝塔值。

**重点关注**：第十题综合性较强。
