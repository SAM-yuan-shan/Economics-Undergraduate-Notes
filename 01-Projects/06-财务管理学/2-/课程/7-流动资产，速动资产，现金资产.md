
# 1 财务比率分析概述
## 1.1 通俗概括：
财务比率分析就像是给公司做体检，通过计算各种指标（比率）来了解公司的健康状况。
## 1.2 核心内容：如何把握财务比率？
对于任何一个财务比率，我们都需要从两个方面来理解它：
1. **如何计算这个比率？** (计算方法)
2. **计算出来的比率说明了什么？** (解读含义)
**重要提示**：在学习初期，**计算的问题比解读的问题更重要**。首先要会算，才能谈得上分析。
## 1.3 财务比率的计算：弄清楚谁除以谁
### 1.3.1 通俗概括：
计算财务比率，关键就是要搞清楚公式里分子（被除数）是谁，分母（除数）是谁。
中文的命名方式有时能帮助我们记忆公式。
![image.png](https://raw.githubusercontent.com/SAMLAY-c/obsidian-photos/university/img/20250529170009149.png)

### 1.3.2 第一类财务比率：某子率 (分母+分子命名法)
#### 1.3.2.1 通俗概括：
这类比率的名字里直接告诉了你分子和分母，通常是名字里先说的做分母，后说的做分子。
- **特点**：名称中既有分母，又有分子。
- **规则**：往往把**分母放在前面，分子放在后面**。
- **例子**：资产负债率
    - 先说“资产”，所以“资产”是分母。
    - 后说“负债”，所以“负债”是分子。
    - 因此，公式是： 资产负债率=资产负债​
- **记忆技巧**：这种命名方式符合中文的表达习惯。
    - 我们常说“母子”，不说“子母”（先有母亲后有孩子）。
    - 我们常说“鸡蛋”，不说“蛋鸡”（先有鸡后有蛋）。
### 1.3.3 第二类财务比率：分子率 (只说分子命名法)
#### 1.3.3.1 通俗概括：
这类比率的名字里只提到了分子是谁，分母需要你自己记住。
- **特点**：名称中只说分子，不说分母。分母需要自行记忆。
- **例子**：速动比率
    - “速动”两个字，指的是分子上的“速动资产”。
    - 分母是什么呢？分母是“流动负债”（这个需要特别记忆）。
    - 因此，公式是： 速动比率=流动负债速动资产​
- **记忆技巧**：钱钟书先生说：“您吃一个鸡蛋，觉着好吃，没有必要非得去见见这下蛋的母鸡。”这类比率就是告诉你“鸡蛋”（分子）好吃，但不直接告诉你“母鸡”（分母）是谁。
## 1.4 财务比率的解读：区分正向与反向指标
### 1.4.1 通俗概括：
解读财务比率，就是要明白这个数字是越高越好，还是越低越好。
不同财务比率有不同的解读方式，但一个共通的内容是区分**正向指标**和**反向指标**。
- **正向指标 (Positive Indicator)**：
    - **定义**：比率的取值越高，企业这方面的能力就越强。
    - **例子**：对于男同学找对象来说，“身高”是个正向指标。比如身高超过 180cm，可能更容易受欢迎。在公司里，像“净利润增长率”，通常是越高越好，代表公司盈利能力增长快。
- **反向指标 (Negative Indicator)**：
    - **定义**：比率的取值越高，企业某方面的能力就越弱（或者风险越高）。
    - **例子**：还是拿找对象举例，“体重”对某些男生来说可能是个反向指标（这里仅为原文举例，无冒犯之意）。在公司里，像“资产负债率”，如果过高，可能说明公司负债多，财务风险大，所以此时它偏向反向指标。
## 1.5 五类财务比率概览
### 1.5.1 通俗概括：
财务比率主要分成五大家族，分别从不同角度评价公司。
这部分我们要学习五类财务比率：
1. **短期偿债能力比率**：衡量企业偿还短期（一年内到期）债务的能力。
2. **长期偿债能力比率**：衡量企业偿还长期（一年以上到期）债务的能力以及资本结构的稳健性。
3. **营运能力比率**：衡量企业经营资产的效率。
4. **盈利能力比率**：衡量企业赚钱的能力。
5. **市价比率**：主要用于上市公司，将股票市价与财务数据联系起来，评估股票价值和投资回报。计算时会用到普通股的每股市价。
**内容多少**：这五类比率的内容有多有少。
- 短期偿债能力比率：内容非常多，很重要。
- 盈利能力比率：内容相对较少。

# 2 短期偿债能力比率详解 (重点)
## 2.1 通俗概括：
这部分是讲公司有没有足够的“活钱”来应付马上要还的债，是考试的重点，内容多且散。
短期偿债能力比率是五类比率中内容最多、考点最为零散、选择题考察概率最高的部分。
## 2.2 引入概念：长期资本和营运资本
### 2.2.1 通俗概括：
在看公司短期还债能力前，我们先要分清楚公司里哪些钱是能长期用的（长期资本），哪些钱是用来日常转的（营运资本）。
资产负债表的基本结构：左边是资产（公司有什么），右边是负债和所有者权益（钱从哪里来）。
#### 2.2.1.1 资产负债表的切分 (三刀切八块)
##### 2.2.1.1.1 通俗概括：
为了分析，我们要从不同角度把资产负债表切开来看，这里主要是按“时间长短”来切。
1. **切分资产 (按短期和长期)**：
    - **流动资产 (Current Assets)**：
        - 定义：企业为交易而持有，预计在一年或一个营业周期里就能变成现金的资产。
        - 特点：周转快，变现快。
        - 例子：
            - **存货 (Inventory)**：生产出来的产品，希望快点卖掉。
            - **应收账款 (Accounts Receivable)**：货卖了但钱还没收回来，希望能尽快收回。
    - **非流动资产 (Non-current Assets)** (原文称长期资产)：
        - 定义：企业为使用而持有，短期内不打算或难以变现的资产。
        - 特点：使用周期长，价值缓慢释放。
        - 例子：
            - **机器设备 (Machinery and Equipment)**：公司自己用，不是用来卖的，希望能用很多年。
2. **切分负债 (按短期和长期)**：
    - **流动负债 (Current Liabilities)**：
        - 定义：在一年或一个营业周期内就要到期偿还的债务。
        - 特点：时间紧迫，火烧眉毛。
        - 例子：**应付账款 (Accounts Payable)**，短期借款。
    - **长期负债 (Long-term Liabilities)**：
        - 定义：还款期限超过一年的债务。
        - 特点：时间较长，可以从长计议。
        - 例子：长期借款，应付债券。
3. **不切分所有者权益**：
    - **所有者权益 (Owner's Equity)**：
        - 定义：企业自己的钱，是股东投入的或者赚来的留存收益。
        - 特点：“铁板一块”，是企业的自有资金，不需要偿还给股东（除非公司清算）。
#### 2.2.1.2 资金来源总结 (资产负债表右边)
- **流动负债**：着急要还的钱。
- **长期负债**：不那么着急还的钱。
- **所有者权益**：根本不用还的钱 (是股东的投入)。
### 2.2.2 长期资本 (Long-term Capital)
#### 2.2.2.1 通俗概括：
长期资本就是公司可以长期使用的钱，主要来自不用急着还的借款和股东的钱。
- **定义**：流动负债不能代表企业的长期资本。构成长期资本的是**长期负债**和**所有者权益**。
- **第一个计算公式 (定义式，必须记住)**： 长期资本=长期负债+所有者权益
    - **来源**：这个公式直接来源于长期资本的定义，即那些不需要在短期内偿还的资金来源。
- **第二个计算公式 (理解就行)**： 长期资本=资产总额−流动负债
    - **来源**：基于会计恒等式：资产 = 负债 + 所有者权益。 进一步分解：资产 = 流动负债 + 长期负债 + 所有者权益。 所以，资产 - 流动负债 = 长期负债 + 所有者权益。 等式右边正好是长期资本的定义。
    - **例子**：公司总资产 $1000万，流动负债 $200万，长期负债 $300万，所有者权益 $500万。
        - 按公式1: 长期资本 = $300万 (长期负债) + $500万 (所有者权益) = $800万。
        - 按公式2: 长期资本 = $1000万 (总资产) - $200万 (流动负债) = $800万。
**注意**：“长期资产” 和 “长期资本” 只有一字之差，但含义完全不同。
- 长期资产：公司拥有的、长期使用的东西 (如机器设备)。
- 长期资本：公司筹集的、可以长期使用的钱。
### 2.2.3 营运资本 (Working Capital)
#### 2.2.3.1 通俗概括：
营运资本就像是公司口袋里的“活钱”减去“马上要付的账单”后剩下的，用来保证日常经营和还债安全的缓冲垫。
营运资本的概念非常重要，选择题经常考察。
#### 2.2.3.2 营运资本的切分与错层地带
资产负债表左右两边按长短期切分时，切面不一定在同一水平线上，中间的错层地带就是营运资本。
#### 2.2.3.3 从短期维度把握营运资本 (安全边际)
##### 2.2.3.3.1 通俗概括：
![image.png](https://raw.githubusercontent.com/SAMLAY-c/obsidian-photos/university/img/20250529170919447.png)

从短期看，营运资本就是流动资产比流动负债多出来的那部分，以防万一流动资产变现不了那么多，导致还不上债。
- **背景**：流动负债马上要还，而长期资产变现慢，指望不上。只能靠流动资产来还流动负债。
- **问题**：如果流动资产和流动负债一样多（比如都是 $100万），安全吗？
    - 不安全！因为流动资产未必能 100% 变现 (比如客户跑路导致应收账款收不回，存货变质卖不掉)。
- **解决方案**：多准备一些流动资产，留有余地。比如有 $100万 流动负债，准备 $150万 流动资产，多出的 $50万 就是一个安全缓冲。
    - 类比：考试 8点开考，你 7点半就到考场，提前的半小时就是安全边际。
- **第一个计算公式 (定义式，从短期角度)**： 营运资本=流动资产−流动负债
    - **来源**：这个公式直接反映了流动资产对流动负债的覆盖程度，以及超出部分的大小。
    - **例子**：公司流动资产 $150万，流动负债 $100万。 营运资本 = $150万 - $100万 = $50万。 这 $50万 就是安全边际。
#### 2.2.3.4 从长期维度把握营运资本 (优质资本的配置)
##### 2.2.3.4.1 通俗概括：
从长期看，营运资本是那些优质的、能长期使用的钱（长期资本）在满足了长期投资需求（买设备盖厂房等）后，剩下来投入到日常经营（流动资产）的部分。
- **背景**：长期资本是优质资本（稳定、成本相对较低），应该优先满足长期资产（如固定资产投资）的资金需求。
- **思路**：为了财务稳健，公司会多配置一些长期资本，超出长期资产需求的部分，就用在了流动资产上。
- **这部分多出来的长期资本用在哪里了？**
    - 长期资产的需求已经满足了。
    - 所以多出来的这部分长期资本，只可能用在流动资产上。
- **第二个计算公式 (从长期角度)**： 营运资本=长期资本−非流动资产 (原文用“长期资产”，即非流动资产)
    - **来源**：这个公式反映了长期资金来源支持了多少非流动资产后，剩余部分用于支持日常运营。
    - **例子**：公司长期资本 $800万 (如前例)，非流动资产 (比如厂房设备) $750万。 营运资本 = $800万 - $750万 = $50万。 这 $50万 是长期资本中用于流动资产的部分。
- **两个公式结果相等**： 因为会计恒等式（资产 = 负债 + 权益），这两个公式计算出来的营运资本数额是相同的。
    - 我们知道：
        - 营运资本 = 流动资产 - 流动负债 (公式1)
        - 营运资本 = (长期负债 + 所有者权益) - 非流动资产 (公式2，代入长期资本定义)
    - 又因为：资产总额 = 流动资产 + 非流动资产
    - 也等于：资产总额 = 流动负债 + 长期负债 + 所有者权益
    - 所以：流动资产 + 非流动资产 = 流动负债 + 长期负债 + 所有者权益
    - 变形：流动资产 - 流动负债 = (长期负债 + 所有者权益) - 非流动资产
    - 可见，左右两边都等于营运资本。
#### 2.2.3.5 营运资本的第三个定义 (资金用途角度)
##### 2.2.3.5.1 通俗概括：
营运资本也可以理解为是那些“长期性质的钱”被用来支持“短期周转的资产”的那一部分。
- **定义**：营运资本是**长期资本用于流动资产的部分**。
- **引申问题**：这部分占流动资产总额的比率是多少呢？这就是**营运资本配置比率**。 营运资本配置比率=流动资产营运资本​
    - **特别注意**：分母是**流动资产**，不是流动负债。
    - **来源**：这个比率衡量了流动资产中有多少是由稳定的长期资本来支持的（通过营运资本的形式）。
    - **例子**：营运资本 $50万，流动资产 $150万。 营运资本配置比率 = $50万 / 150万≈0.3333 或 33.33%。
#### 2.2.3.6 营运资本总结 (三个定义，三个公式)
|                            |                    |
| -------------------------- | ------------------ |
| **定义**                     | **公式**             |
| 1. 流动资产超过流动负债的部分           | 营运资本=流动资产−流动负债     |
| 2. 长期资本超过非流动资产（长期资产）的部分    | 营运资本=长期资本−非流动资产    |
| 3. 长期资本用于流动资产的部分 (并引出配置比率) | 营运资本配置比率=流动资产营运资本​ |
#### 2.2.3.7 解读营运资本
##### 2.2.3.7.1 通俗概括：
一般来说，营运资本越多，公司短期还债就越安全，但它是个具体金额，不好直接比较，有时需要变成比率来看。
- **正向指标**：营运资本是短期偿债能力的一个正向指标。数额越大，安全边际越厚实，短期偿债能力越强。
- **绝对数，可比性差**：营运资本是一个金额，比如 A公司营运资本 $1000万，B公司 $100万。不能直接说 A就比 B好很多，因为公司规模可能差很多。
- **合理性判断**：需要通过营运资本与短期债务的存量比率 (如流动比率、速动比率，后面会讲) 来把握。
- **通常为正数，也可能为负数**：如果流动负债大于流动资产，营运资本就是负数，说明短期内资金紧张。
**暂停点**：至此，我们学习了长期资本的两个公式，营运资本相关的三个公式，一共五个。建议你先记住它们再继续。
## 2.3 流动比率

### 2.3.1 流动比率 (Current Ratio)
#### 2.3.1.1 通俗概括：
这个比率是看公司的“活钱”（流动资产）够不够还“马上要付的账单”（流动负债），是它的几倍。
- 公式： 流动比率=流动负债流动资产​
- **逻辑**：“远水解不了近渴”，偿还流动负债主要靠流动资产。流动比率就是看流动资产是流动负债的多少倍。
- **解读**：显然，流动比率越高，意味着企业偿还流动负债的能力就越强。
- **重要性**：流动比率非常重要，是判断短期偿债能力**首选**的财务比率。
- **例子**：流动资产 $150万，流动负债 $100万。 流动比率 = $150万 / 100万=1.5。意思是流动资产是流动负债的 1.5倍。

### 2.3.2 流动比率指标的深入解读
#### 2.3.2.1 通俗概括：
流动比率一般认为 2 左右比较好，但不是绝对的，还要看公司“活钱”的质量怎么样，而且这个比率本身也有一些不完美的地方。
- **默认基准值 (Benchmark)**：2。
    - 生产型企业的最低流动比率一般认为是 2。
    - **来源/逻辑**：传统上认为，流动资产里有一半是变现能力较差、不太靠谱的**存货**。去掉这部分不靠谱的存货后，剩下那部分比较靠谱的流动资产，至少应该能 1:1 地覆盖流动负债。所以，总的流动资产应该是流动负债的 2倍。
    - **注意**：不是说流动比率低于 2 就一定还不上债，稍微低一些也未必大惊小怪。
- **流动比率的缺陷 (Limitations)**：
    - 计算时假设：企业拿**全部**流动资产偿还**全部**流动负债。这个假设简单粗暴，“颗粒度比较粗”。
    1. **缺陷一：高估现金偿付压力**
        - 它假定全部流动负债都要用现金偿还。
        - **现实**：一些经营性的应付项目 (如应付账款)，在企业持续经营中可以自动滚动续期 (比如这个月欠供应商的钱，下个月还，但同时又产生了新的欠款)，并不需要全部用现金一次性还清。
        - **普遍性**：这个缺陷不仅限于流动比率，只要用到流动负债这个整体数据，都未对其进行甄别。
    2. **缺陷二：高估可用于偿债的流动资产**
        - 它假定所有的流动资产都可以拿来变现偿债。
        - **现实**：一些流动资产是企业持续经营所必需的 (比如最低的现金保有量，必要的原材料库存)，不能都拿去还债。“砸锅卖铁还债”，日子就没法过了。
    3. **缺陷三：未考虑流动资产内部结构 (重要)**
        - 流动资产是个“大杂烩”，里面什么都有，资质良莠不齐。
        - 有些资产 (如存货) 的账面金额与实际能变现的金额可能有较大差距。
        - 指望这些资产偿还流动负债并不可靠。
        - **引出后续内容**：需要对流动资产“掀开锅盖看看”，逐项甄别筛选，这就是接下来要讲的速动比率等。

# 3 速动资产和现金资产
## 3.1 通俗概括：
因为流动资产里有些东西变现太慢或不靠谱，所以我们要进一步筛选，找出那些能快速变成钱的“速动资产”，以及最最靠谱的“现金资产”。
## 3.2 基本逻辑：层层筛选
偿还短期债务，主要靠流动资产，但并非所有流动资产都靠谱。
1. 从 **流动资产 (大箩筐)** 中筛选出偿债能力**相对靠谱**的 → **速动资产 (小箩筐)**。
2. 从 **速动资产 (小箩筐)** 中再筛选出偿债能力**绝对靠谱**的 → **现金资产 (精品)**。
## 3.3 第一轮筛选：从流动资产到速动资产
### 3.3.1 通俗概括：
我们要把流动资产里那些“磨洋工”的、不太能指望得上的部分（比如存货、预付款）踢出去，剩下的就是速动资产。
流动资产全家福（例子）：
- 货币资金
- 交易性金融资产
- 应收票据
- 应收账款
- 预付款项
- 存货
- 一年内到期的非流动资产
- 其他流动资产
**末位淘汰原则进行甄别**：
1. **首先淘汰“打酱油”的**：
    - **一年内到期的非流动资产**、**其他流动资产**：这些科目金额具有偶然性，不代表正常的变现能力。
    - **结果**：淘汰出局。
2. **关注存货 (Inventory)**：
    - **变现速度**：比应收账款慢一拍 (应收账款是货已卖出等收款，存货是货还没卖)。
    - **不确定性**：
        - 能否实现销售？
        - 实体上可能已毁损报废。
        - 法律权属上可能已抵押质押。
        - 可变现净值未必等于账面价值 (可能滞销打折)。
    - **结论**：存货不是一项靠谱的偿债资产。
    - **结果**：淘汰出局。
3. **关注预付账款 (Prepayments)**：
    - **性质**：存货的前身。企业付钱给供应商，等着收货。
    - **转化**：供应商发货后，预付账款转为存货。
    - **逻辑**：存货因为变现慢被淘汰，它的前身预付账款更不可能是速动资产。
    - **结果**：淘汰出局。
**筛选结果**：
- **非速动资产 (Non-Quick Assets)**：被淘汰的，偿债能力不靠谱。
    - 预付账款
    - 存货
    - 一年内到期的非流动资产
    - 其他流动资产
- **速动资产 (Quick Assets)**：成功突围的，变现速度较快，偿债能力较强。
    - 货币资金 (Cash)
    - 交易性金融资产 (Trading Financial Assets)
    - 应收账款 (Accounts Receivable)
    - 应收票据 (Notes Receivable)
    - **其他应收款 (Other Receivables)** - 不要漏掉！
### 3.3.2 速动资产的计算方法
#### 3.3.2.1 通俗概括：
算速动资产有两种方法：一种是把所有算作速动资产的项目加起来；另一种是用流动资产总数减掉那些不算速动资产的项目。
1. 加法 (把入选的加起来)：
    速动资产=货币资金+交易性金融资产+应收票据+应收账款+其他应收款
    - **特别强调**：不要漏掉**其他应收款**。它虽然在资产负债表排得靠后，但名字里带“应收”，属于应收家族。
    - **例子**：某公司有货币资金 $50万，交易性金融资产 $20万，应收账款 $100万，应收票据 $30万，其他应收款 $10万，存货 $80万，预付款项 $5万。 速动资产 = $50 + $20 + $100 + $30 + $10 = $210万。
2. 减法 (从流动资产中扣除不合格的)：
    速动资产=流动资产−(存货+预付账款+一年内到期的非流动资产+其他流动资产)
    - **特别提醒**：注意**预付账款**不是速动资产，而应收款项是。
    - **简化情况**：有的考题中假设非速动资产主要就是存货，则： 速动资产≈流动资产−存货 (这是一个常见的简化，但要看题目条件)
    - **例子**：某公司流动资产合计 $300万，其中存货 $80万，预付款项 $5万，一年内到期的非流动资产 $0万，其他流动资产 $0万。 速动资产 = $300 - ($80 + $5 + $0 + $0) = $215万。 (如果该公司流动资产就是前面加法例子中列出的那些项目总和 50+20+100+30+10+80+5=295万，那么 速动资产 = $295 - 80 - 5 = 210万，和加法结果一致。)
## 3.4 第二轮筛选：从速动资产到现金资产
### 3.4.1 通俗概括：
在速动资产里，应收账款也可能收不回来，所以我们再挑一次，只留下最稳妥的“现金资产”，基本上就是手上的钱。
- **速动资产的薄弱环节**：应收账款。
    - 可能变成坏账 (客户跑路)。
    - 坏账准备可能计提不足。
    - 年末余额不一定代表全年平均水平 (季节性波动)。
- **筛选结果**：把应收账款也排除在外。
- **决赛总冠军：现金资产 (Cash Assets)**
    - **货币资金 (Cash and Cash Equivalents)**：流动性最强，直接拿来偿债。
    - **定义**：最终当选现金资产的**只有一项**，就是**货币资金**。
    - **特别注意**：按注会财管口径，**交易性金融资产虽然变现能力也很强，但不算作现金资产**。现金资产就是指“真金白银”。
    - **例子**：某公司速动资产 $210万，其中货币资金 $50万，交易性金融资产 $20万，应收类款项 $140万。 则现金资产 = $50万 (仅货币资金)。

**流动性与偿债能力分析**：
- **货币资金**：
    - 属于**现金资产**。
    - 流动性最强，偿债能力最靠谱。
- **应收账款** (+交易性金融资产、应收票据、其他应收款)：
    - 属于**速动资产**。
    - 距离货币资金**一步之遥** (客户付款就能变现)。
- **存货**：
    - 属于**非速动资产**。
    - 距离货币资金有**两步之遥** (先要卖出去变应收账款，再收回应收账款变货币资金)。
    - 销售环节有巨大不确定性。
- **预付账款**：
    - 属于**非速动资产**。
    - 距离货币资金有**三步之遥** (先变存货，再变应收账款，最后变货币资金)。
    - 更不靠谱。
**注意**：流动资产在营业周期中是按箭头方向依次出现的，不能“开倒车”（比如预付账款一般是等供应商发货变成存货，而不是供应商直接退款变回货币资金，虽然理论上可以但不是常规商业逻辑）。
## 3.7 练习题：判断资产分类
### 3.7.1 通俗概括：
我们来做个小练习，看看哪些科目属于流动资产、速动资产或现金资产。

|                 |              |              |              |                                        |
| --------------- | ------------ | ------------ | ------------ | -------------------------------------- |
| **报表科目**        | **是否属于流动资产** | **是否属于速动资产** | **是否属于现金资产** | **理由 (小白解读)**                          |
| **货币资金**        | ✅            | ✅            | ✅            | 手上的钱，最灵活，三者8都是。                        |
| **交易性金融资产**     | ✅            | ✅            | ❌            | 很容易卖掉变钱，但不是直接的钱，所以是流动和速动，但按严格定义不是现金资产。 |
| **应收账款**        | ✅            | ✅            | ❌            | 别人欠的钱，应该能收回，算速动，但毕竟还没到手，不算现金资产。        |
| **应收票据**        | ✅            | ✅            | ❌            | 和应收账款类似，是更正式的欠条，算速动，不算现金资产。            |
| **存货**          | ✅            | ❌            | ❌            | 压在仓库的货，得先卖掉才能变钱，变现慢，不算速动和现金资产。         |
| **预付账款**        | ✅            | ❌            | ❌            | 预交给别人的钱，指望换回存货，比存货还难变现，不算速动和现金资产。      |
| **其他应收款**       | ✅            | ✅            | ❌            | 其他零星的别人欠的钱，带“应收”也算速动，但不是现金。            |
| **一年内到期的非流动资产** | ✅            | ❌            | ❌            | 本来是长期用的，但快到期了，算流动，但性质特殊，一般不算速动。        |
| **其他流动资产**      | ✅            | ❌            | ❌            | 一些杂项流动资产，通常变现能力不确定，不算速动。               |
**总结**：
- 表格中所有科目都属于**流动资产**。
- **速动资产**主要包括：货币资金、交易性金融资产、各种应收款项 (应收账款、应收票据、其他应收款)。**不包括**：存货、预付账款以及那两个“打酱油”的。
- **现金资产**通常**只有货币资金**这一项。
