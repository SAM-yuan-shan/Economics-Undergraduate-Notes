好的，我们来深入学习长期偿债能力比率中的“存量比率”，特别是资产负债率、产权比率和权益乘数这三个密切相关的指标。

# 1 核心长期偿债能力存量比率：三位一体

## 1.1 通俗概括：

这三个比率就像一个家庭的三个成员，都反映了公司家当（资产）、欠别人的钱（负债）和自己的本钱（权益）之间的基本构成关系。知道一个，另外两个也就能猜出大概。

这三个比率（资产负债率、产权比率、权益乘数）归根到底体现的是资产负债表的基本结构，即**资产、负债、所有者权益**三者之间的比例关系。

---

## 1.2 资产负债率 (Debt to Asset Ratio)

### 1.2.1 通俗概括：

资产负债率就是看看公司总的家当里，有多少是靠借钱（负债）得来的。

- **公式**： 资产负债率=资产总额负债总额​
- **命名规则回顾**：属于“母子率”。
    - 先说“资产”，所以“资产总额”在分母。
    - 后说“负债”，所以“负债总额”在分子。
    - **千万不要记反了！**
- **记忆方法**：想象一个人“**背上**沉重的**债务**包袱”。
    - “背上”意味着**负债在上面（分子）**。
    - “包袱”的基础是这个人所拥有的（总资产），所以**资产在下面（分母）**。
- **例子**：如果一家公司总资产 $1000万元，总负债 $600万元。
    - 资产负债率 = $600万 / 1000万=0.6 或 60%。
    - 这意味着公司 60% 的资产是通过负债形成的。

---

## 1.3 产权比率 (Debt to Equity Ratio)

### 1.3.1 通俗概括：

产权比率是比较公司借来的钱（负债）和股东自己投的钱（所有者权益）哪个更多。

- **公式**： 产权比率=所有者权益总额负债总额​
- **记忆方法**：“**债台高垒**”在“**权益基石**”之上。
    - 所有者权益是企业自有资金，是财务大厦的**基石（分母）**。
    - 企业在权益的基础上借入负债，债务借得越多，就像在基石上把债堆得越高（**负债在分子**），大厦就越摇摇欲坠。
- **“产权”的理解**：
    - 这里的“产权”是一个整体词，指资产的最终归属。不要拆成“资产”和“权益”去对应公式。
    - 企业的资产最终归属于谁？无外乎是**债权人（提供了负债）**和**股东（提供了所有者权益）**。
    - 产权比率就是从账面价值角度看，这两方投入的比例关系。
    - **例子**：你们家的房子（资产），房产证上写了你和你爱人的名字。假设房子价值 $100万。如果银行贷款（负债）有 $60万，你们夫妻俩自己出的首付和后续还款中属于本金的部分（所有者权益）是 $40万。
        - 那么，从资金来源看，外部债权人（银行）的“产权”份额是 $60万，你们（股东）的“产权”份额是 $40万。
        - 产权比率（负债/权益）= $60万 / 40万=1.5。
        - （这里用房子的例子帮助理解“资产归属”和“负债/权益”的对比，实际个人房产的“产权比率”不是这么算的，主要是公司财务概念。）
- **公司例子**：公司总负债 $600万元，所有者权益 $400万元。
    - 产权比率 = $600万 / 400万=1.5。
    - 这意味着公司每 $1元的所有者权益，就对应着 $1.5元的负债。

---

## 1.4 权益乘数 (Equity Multiplier)

### 1.4.1 通俗概括：

权益乘数是看股东每投进 $1块钱的本钱（所有者权益），能撬动多少总家当（总资产）。

- **公式**： 权益乘数=所有者权益总额资产总额​
- **“乘数”的理解**：它是一个放大倍数，正常情况下取值 ≥1。它把所有者权益“放大”到总资产的规模。
- **记忆方法**：“**以小博大**”的杠杆。
    - 股东出资（所有者权益）是“小”的本钱。
    - 通过举债经营（财务杠杆），用这部分本钱控制和运营更大规模的总资产（“博大”）。
    - 放大的倍数就是资产相对于权益的倍数。
- **例子**：企业设立之初，股东出资 $100万元（所有者权益）。但办企业需要 $200万元的资产，于是又向银行借了 $100万元（负债）。
    - 总资产 = $200万元。
    - 权益乘数 = $200万 (资产) / 100万(权益)=2。
    - 意思是股东用 $100万的本钱，撬动了 $200万的生意（资产规模），放大了 2倍。

## 1.5 三个比率的关系与记忆技巧

### 1.5.1 核心关系：会计恒等式

资产 = 负债 + 所有者权益 (A=L+E)

- 只要知道 A、L、E 中的任意两个，就能算出第三个，进而算出这三个比率。

### 1.5.2 等效性与同向变动

1. **等效关系**：知道三个比率中的任何一个，都可以推算出另外两个。
    - 例如，已知资产负债率 (L/A)，因为 A = L+E，所以 L/A = L/(L+E)。可以解出 L/E (产权比率)。而 A/E = (L+E)/E = L/E + 1 (权益乘数)。
2. **同向变动**：这三个比率是同向变动的。
    - 如果资产负债率提高 (意味着负债占比增加)，那么产权比率和权益乘数也必然随之提高。
    - **原因**：它们都反映了企业利用债务杠杆的程度。杠杆用得越多，这三个比率通常都会越高。
3. **都是长期偿债能力的反向指标**：
    - 任何一个比率提高，都意味着企业的负债水平相对更高，财务风险更大，长期偿债能力可能变差。

### 1.5.3 记忆方法：“X1法则” (在资产负债表上画图)

在简化的资产负债表上（左边资产A，右边上方负债L，右边下方权益E）：

```
  资产(A) | 负债(L)
          |---------
          | 权益(E)
```

1. **画一个“X”**：
    
    - **一撇 ( \ )**：从右上方的**负债(L)** 出发，划到左边的**资产(A)**。
        - 对应**资产负债率 = 负债(L) / 资产(A)**。
    - **一捺 ( / )**：从左边的**资产(A)** 出发，划到右下方的**权益(E)**。
        - 对应**权益乘数 = 资产(A) / 权益(E)**。
2. **写一个阿拉伯数字“1”**：
    
    - 从右上方的**负债(L)** 出发，向下滑到右下方的**权益(E)**。
        - 对应**产权比率 = 负债(L) / 权益(E)**。

**提示**：这些记忆方法主要针对初学者。当您做题多了，公式熟悉了，自然就能记住，不需要拐杖了。

## 1.6 解读资产负债率

### 1.6.1 通俗概括：

资产负债率越高，说明公司欠的债越多，还钱的压力就越大；太高了就像水淹到脖子，很危险。但太低了也可能说明公司太保守，没充分利用借钱发展的机会。

- **反向指标**：衡量长期偿债能力的反向指标。
- **比率高低的影响**：
    - **很高** (如 90%)：意味着公司资产中绝大部分是靠借债形成的，“欠了一屁股债”。偿债压力巨大。就像水已经淹到脖子，资产稍微出点问题（比如贬值或无法变现）就可能还不上债。
    - **超过 100% (即 > 1)**：意味着**资不抵债**，总资产还不够还总负债，水已经没过头顶，公司处于非常危险的财务困境。
    - **很低** (如 10%)：意味着公司手头资产很多，但债务很少。还债是“稀松平常”的事，非常安全。就像水只淹到脚脖子。
- **也体现举债能力**：
    - 银行在审批贷款时，如果看到一家企业资产负债率很低，会觉得这家企业还款能力强，风险小，因而更愿意给它放贷。所以，适度的资产负债率，或者说较低的资产负债率，反而可能意味着较强的后续举债能力。
- **基准值：约 50%** (可视为及格线)
    - 超过 50% 可能意味着偿债能力存在问题。
    - **50% 的逻辑来源**：
        - 会计上的资产账面价值通常基于“持续经营”假设。
        - 但考虑偿债能力，尤其是极端情况（如破产清算），资产紧急出售时往往要**打折**，卖不上账面价。
        - 经验上，破产清算时资产售价可能达不到账面价值的一半。
        - 所以，资产能背负得起的债务，最多也就是账面价值的一半，即资产负债率顶多 50%。
    - **基准值不是绝对的**：
        - 还要看**资产的变现能力**。
            - **资产变现能力强** (如房地产企业的土地和房产，通用性强，易变现)：企业可以承担更高的资产负债率。
            - **资产变现能力弱** (如互联网企业的很多无形资产，一旦破产清算可能不值钱)：这类企业的资产负债率通常会压得很低。

## 1.7 解读产权比率和权益乘数

### 1.7.1 通俗概括：

这两个比率都反映了公司用了多少“杠杆”（借了多少钱来办事）。杠杆能放大收益，也能放大风险，赚钱时赚更多，赔钱时也赔更惨。

- **常用的财务杠杆比率**：
    - 财务杠杆就是“以小博大”，用较少的自有资金（权益）控制较多的资产，以期获得更高的权益报酬率。
    - **结果**：放大收益，也放大风险。能“锦上添花”，也会“落井下石”，但不能“雪中送炭”（如果本身不赚钱，杠杆只会让亏损更严重）。
- **首先是偿债能力指标**：
    - 与资产负债率一样，也是长期偿债能力的**反向指标**。比率越高，风险越大。
- **其次与盈利能力息息相关**：
    - 特别是**权益乘数**，它能将**资产净利率 (ROA)** 放大为股东的**权益净利率 (ROE)**。
        - 基本公式（杜邦分析核心）：ROE=ROA×权益乘数 (在不考虑税和利息的简化情况下，或更准确地说是 税后ROA * 权益乘数 * 调整系数)
        - 这体现了杠杆放大收益的作用，但同时也增加了权益净利率的风险（波动性）。
    - 这个问题在后续学习盈利能力指标时会详细解释。

## 1.8 数字游戏型习题

### 1.8.1 通俗概括：

这类题就是给你一个比率，让你算另外几个，纯粹是数学换算，熟悉公式和用对方法就行。

**解题建议**：用**算术方法**（代入特殊数值），不要用代数方法（设未知数XYZ），除非算术法失效或题目明确要求公式推导。

**例题1**：已知权益乘数等于 4，问资产负债率、产权比率各是多少？

- **思路**：
    1. 权益乘数 = 资产 / 权益 = 4。
    2. 不妨设：**权益 = 1**。那么，**资产 = 4**。
    3. 根据会计恒等式：资产 = 负债 + 权益。 所以，负债 = 资产 - 权益 = 4−1=3。
    4. 现在我们有了：资产=4，负债=3，权益=1。
    5. 计算其他比率：
        - 资产负债率 = 负债 / 资产 = 3/4=0.75 (或 75%)。
        - 产权比率 = 负债 / 权益 = 3/1=3。

例题2：下列关于财务比率之间关系的公式正确的有哪些？

(假设选项为：A. 权益乘数 - 产权比率 = 1 等)

- **思路1：算术法 (代入数值验证)**
    
    1. 不妨设：资产 : 负债 : 权益 的比例关系是 5:2:3 (因为 2+3=5，满足恒等式)。
        - (设值时尽量让计算简单，且能区分不同比率)
    2. 计算三个比率：
        - 资产负债率 = 负债/资产 = 2/5=0.4。
        - 产权比率 = 负债/权益 = 2/3≈0.67。
        - 权益乘数 = 资产/权益 = 5/3≈1.67。
    3. 将这些比率值代入题目给出的选项公式中进行验证。
        - 例如，验证 A选项 "权益乘数 - 产权比率 = 1"：
            - 1.67−0.67=1。此选项正确。
    4. **风险**：用特殊数值法可能有“歪打正着”的风险，即你设的数字恰好让一个错误的公式成立了。但对于选择题，这通常是快速有效的方法。
- **思路2：代数法 (用字母推导)**
    
    1. 设资产 = A, 负债 = D (Debt), 权益 = E (Equity)。
    2. 我们知道 A = D + E。
    3. 将各比率用字母表示：
        - 资产负债率 = D/A
        - 产权比率 = D/E
        - 权益乘数 = A/E
    4. 推导选项中的公式：
        - 例如，验证 A选项 "权益乘数 - 产权比率 = 1"：
            - 左边 = (A/E) - (D/E) = (A-D)/E
            - 因为 A-D = E (由 A=D+E 变形得到)
            - 所以，左边 = E/E = 1。
            - 左边 = 右边 (1=1)。此选项公式恒成立。

(BCD选项的验证同理)

这三个核心的存量比率我们就先学到这里。

%%## 1.9 长期资本负债率 (Long-term Capital Gearing Ratio / Long-term Debt to Long-term Capital Ratio)

### 1.9.1 通俗概括：

这个比率是看在公司能够长期使用的钱（长期资本）里面，有多少是通过借长期债得来的。

首先回顾**长期资本 (Long-term Capital)** 的概念和公式：

- 长期资本=长期负债+所有者权益 或者
- 长期资本=总资产−流动负债

理解长期资本负债率，我们需要把资产负债表切分得更细一点：

- 资产 → 流动资产、非流动资产 (长期资产)
- 负债 → 流动负债、长期负债 (非流动负债)

**“说文解字”把握长期资本负债率**：

1. **“长期资本”指什么？** 指的是**长期负债**和**所有者权益**这两项之和。
2. **长期资本里包含了多少“负债”？** 这里特指**长期负债**。流动负债不属于长期资本的范畴。
3. **比率计算**：用“长期负债”除以“长期资本”。

- **公式**： 长期资本负债率=长期资本长期负债​ 或者代入长期资本的构成： 长期资本负债率=长期负债+所有者权益长期负债​

### 1.9.2 从不同角度理解长期资本负债率

1. **从长期角度：体现长期资本的构成**
    
    - 这个指标反映了企业长期融资来源中，长期债务资金所占的比重。
    - 在财务管理中，单说“资本”二字，不加“营运”，通常指的就是长期资本。
    - **资本结构 (Capital Structure)** 指的就是长期资本的结构。因此，在资本结构管理中，经常会用到长期资本负债率这个指标。
    - **例子**：如果一家公司的长期资本负债率是 40%，意味着其长期资金来源中有 40% 是长期借款，另外 60% 是股东权益。
2. **从短期角度：剔除流动负债影响的“纯化版”资产负债率**
    
    - 回顾资产负债率 = 总负债 / 总资产。
    - 如果我们在资产负债率公式的分子分母上**同时减掉流动负债**：
        - 新分子 = 总负债 - 流动负债 = **长期负债**。
        - 新分母 = 总资产 - 流动负债 = (流动负债 + 长期负债 + 所有者权益) - 流动负债 = **长期负债 + 所有者权益 = 长期资本**。
        - 所以，总资产−流动负债总负债−流动负债​=长期资本长期负债​=长期资本负债率。
    - **特点**：由于流动负债经常变化、不稳定，剔除了流动负债的影响后，长期资本负债率这个指标变得**更加稳定**，更能反映公司长期的资本结构特征。

### 1.9.3 长期资本负债率的计算与解读总结

- **计算**： 长期资本负债率=长期负债+所有者权益长期负债​
- **解读特点：“扬长避短”**
    - **扬长 (优点)**：能够体现**长期资本的构成**，适合用于资本结构的管理和分析。
    - **避短 (稳定性)**：计算中剔除了波动较大的**流动负债**的影响，所以指标相对**稳定**。
    - 它也是一个**反向指标**，比率越高，对长期债权人的保障程度可能越低，财务风险也相对较大。

## 1.10 综合练习题：多比率计算

### 1.10.1 通俗概括：

这类题会给出一堆资产负债数据，让你算出一大串前面学过的短期和长期还钱能力指标，考验你的综合运用能力。

**题目信息 (示例)**：

- 流动资产: $700万元
- 非流动资产: $1300万元
- 流动负债: $300万元
- 非流动负债 (长期负债): $740万元
- (所有者权益需要自己推算)

**要求**：计算流动比率、营运资本配置率、资产负债率、产权比率、权益乘数、长期资本负债率等八个指标。

**解题步骤**：

1. **计算基础数据**：
    
    - 总资产 = 流动资产 + 非流动资产 = $700 + 1300 = 2000万元。
    - 总负债 = 流动负债 + 非流动负债 = $300 + 740 = 1040万元。
    - 所有者权益 = 总资产 - 总负债 = $2000 - 1040 = 960万元。
    - 长期资本 = 非流动负债 (长期负债) + 所有者权益 = $740 + 960 = 1700万元。
        - (或者：长期资本 = 总资产 - 流动负债 = $2000 - 300 = 1700万元)。
    - 营运资本 = 流动资产 - 流动负债 = $700 - 300 = 400万元。
2. **计算各项比率**：
    
    - **流动比率** = 流动资产 / 流动负债 = 700/300≈2.33。
    - **营运资本配置率** = 营运资本 / 流动资产 = 400/700≈0.57 (或 57%)。
    - **资产负债率** = 总负债 / 总资产 = 1040/2000=0.52 (或 52%)。
    - **产权比率** = 总负债 / 所有者权益 = 1040/960≈1.08。
    - **权益乘数** = 总资产 / 所有者权益 = 2000/960≈2.08。
    - **长期资本负债率** = 长期负债 / 长期资本 = 740/1700≈0.435 (或 43.5%)。(原文0.44可能是四舍五入)

**(另一道数字游戏题示例，已知长期资本、营运资本、所有者权益，求长期资本负债率)**

- 已知：长期资本(LTC) = $1200万 (这是题目笔误，应为其他数据，假设是题目想让你求的)，营运资本(WC) = $800万，所有者权益(E) = $1400万。
    - **修正题干理解**：原文中“已知长期资本是1200万元”与后续推导“长期资本等于2000万元”矛盾。我们按其推导逻辑，假设题目给出的是“长期资产(NFA)”和“营运资本(WC)”。
    - 假设题目给出：**非流动资产 (长期资产 NFA)** = $1200万元，营运资本 (WC) = $800万元，所有者权益 (E) = $1400万元。
    - **求解**：
        1. 根据公式：营运资本 = 长期资本 - 非流动资产 (长期资产) 所以，长期资本 = 营运资本 + 非流动资产 = $800 + 1200 = 2000万元。
        2. 长期资本 = 长期负债 (LTD) + 所有者权益 (E) 所以，长期负债 = 长期资本 - 所有者权益 = $2000 - 1400 = 600万元。
        3. 长期资本负债率 = 长期负债 / 长期资本 = 600/2000=0.30 (或 30%)。

## 1.9 利息保障倍数 (Interest Coverage Ratio / Times Interest Earned - TIE)

### 1.9.1 通俗概括：

这个比率是看公司赚的钱（税前利润并加回利息）是需要支付的利息的好几倍，倍数越高，说明公司付利息的能力越强，越安全。

讲完了体现还本能力的存量比率，接下来我们学习反映**付息能力**的流量比率。

- 公式：
    
    利息保障倍数=利息支出 (总额)息税前利润 (EBIT)​
    
- **逻辑**：
    
    - 分母“利息支出”是需要保障的对象（可以想象成一个人）。
    - 分子“息税前利润”是拿来保障这个对象的（可以想象成这个人头顶撑着的一把伞）。
    - 伞的面积越大 (EBIT越高)，保障越充分，被“日晒雨淋”（付不起利息）的风险就越低。
- **分子：息税前利润 (EBIT - Earnings Before Interest and Taxes)**
    
    - 代表企业经营活动的全部成果，可以理解为**税前经营收益**。
    - **计算方法1 (倒推法 - 常用)**： EBIT=净利润+所得税费用+利息费用(计入财务费用的部分)
        - **理解这个公式的逻辑 (切蛋糕)**：
            1. EBIT是企业经营活动烤出来的“大蛋糕”。
            2. **第一刀**：债权人先切走一块，即“利息费用”。
            3. **第二刀**：税务局再拿走一块，即“所得税费用”。
            4. **最后剩下**：留给股东的“净利润”。
            5. 把这三块重新加起来，就还原了整个蛋糕EBIT。
        - **理解这个公式的逻辑 (还原法)**：
            1. 从利润表最底端的“净利润”出发（这是税后、息后的利润）。
            2. **加回所得税**：从税后还原到税前。
            3. **加回利息费用**：从息后还原到息前（这里的“息”指计入利润表影响了净利润的利息费用）。
            4. 这样就得到了息税都未扣除前的利润。
        - EBIT是非常重要的财务指标，后续章节还会遇到。
    - **计算方法2 (顺推法 - 当倒推法无法使用时)**： EBIT=营业收入−营业成本−税金及附加−销售费用−管理费用
        - **注意**：不减“财务费用”，因为财务费用主要是利息费用，而我们要算的是“息前”利润。销售费用和管理费用属于经营费用，需要扣除。
    - **计算方法3 (结合成本形态)**： EBIT=营业收入−变动成本总额−固定经营成本
- **分母：利息支出 (总额)**
    
    - **口径不同于分子中的“利息费用”**：
        - 分子中的“利息费用”：通常指计入利润表、冲减了当期利润的**费用化利息**。
        - 分母中的“利息支出”：指企业需要实际支付给债权人的**全部利息**，包括：
            - **费用化利息** (计入利润表财务费用)。
            - **资本化利息** (与购置或建造固定资产等相关，符合资本化条件，计入相关资产成本，未直接冲减当期利润)。
    - **原因**：
        - 银行才不管你企业内部会计怎么处理（费用化还是资本化），借款合同上约定的利息，企业都得按时足额支付。所以分母要用全口径的利息支出。
        - 分子用费用化利息是因为从净利润倒推EBIT时，只需要加回那些在计算净利润过程中被减掉的费用化利息。

**趁热打铁练习：判断利息保障倍数公式中分子分母是否包含特定利息**

|   |   |   |
|---|---|---|
|**项目**|**分子(EBIT计算中加回的利息)**|**分母(总利息支出)**|
|**费用化利息**|✅|✅|
|**资本化利息**|❌|✅|

### 1.9.2 解读利息保障倍数

- **正向指标**：付息能力的正向指标。伞越大，保障越足。倍数越高，偿还利息的缓冲越多。
- **间接反映还本能力**：虽然主要考察付息能力，但如果企业能持续按时足额支付利息，维持良好信誉，银行可能更愿意展期或提供新贷款（借新还旧），从而间接帮助解决还本问题。
- **基准值：1 (及格线)**
    - **小于 1**：不及格。意味着企业经营赚的钱还不够付利息，需要股东倒贴钱来付息，这种亏本生意不可持续。
    - **约等于 1 (卡线及格)**：非常危险！
        - **原因**：
            - 保障对象“利息支出”是合同约定的，通常是确切金额，且需用真金白银支付。
            - 拿来保障的“EBIT”是会计核算结果，可能虚（非现金收益），且不稳定（受经营风险影响会波动）。
            - 用一个不确定且可能虚的EBIT去保障一个确定且实在的利息支出，如果只是一比一保障，EBIT稍微出点问题就付不起利息了。
        - **类比**：会计、经济法、税法考试考60分不代表实际工作能力达标。财管考60分万岁！（这是原文的调侃）

### 1.9.3 利息保障倍数习题

习题1：利息保障倍数计算公式中，分子EBIT计算时加回的“利息费用”应如何取值？

A. 只包括资本化利息

B. 只包括费用化利息

C. 包括费用化和资本化利息

D. 根据情况确定

**答案**：B. 只包括费用化利息。

修改提问：如果问分母上的“利息支出”应如何取值？

答案：C. 包括费用化和资本化利息。

**习题2**：某公司净利润 $7500万元，所得税 $2500万元，利息支出共计 $2500万元 (其中费用化利息 $2000万元，资本化利息 $500万元)。问利息保障倍数是多少？

- **计算EBIT**：
    - EBIT = 净利润 + 所得税 + 费用化利息
    - EBIT = $7500万 + $2500万 + $2000万 = $12000万元。
- **利息支出总额** (分母) = $2500万元 (费用化$2000万 + 资本化$500万)。
- **利息保障倍数** = EBIT / 利息支出总额 = $12000万 / 2500万=4.8。

**习题3：判断下列事项对利息保障倍数的影响** (假设其他条件不变)

|        |                      |        |                                                                                          |
| ------ | -------------------- | ------ | ---------------------------------------------------------------------------------------- |
| **序号** | **事项描述**             | **影响** | **理由 (小白解读)**                                                                            |
| a      | 营业收入增加               | ⬆️     | 收入增加，通常EBIT会增加 (蛋糕变大)，利息支出不变，所以倍数提高。                                                     |
| b      | 营业成本率下降              | ⬆️     | 成本率下降，利润空间增大，EBIT增加，倍数提高。                                                                |
| c      | 销售费用、管理费用减少          | ⬆️     | 这些是经营费用，减少了它们，EBIT会增加，倍数提高。                                                              |
| d      | 债务的利息率下调             | ⬆️     | 利息支出总额减少 (伞下的人变小了)，EBIT不变，所以倍数提高。                                                        |
| e      | 将更多的利息做资本化处理 (费用化减少) | 不变     | **分子EBIT不变**：EBIT是不扣利息的，所以利息在会计上是费用化还是资本化，不影响EBIT的计算结果。**分母利息支出总额不变**：银行要收的总利息不变。因此倍数不变。 |
| f      | 所得税税率下调              | 不变     | EBIT是税前利润，利息支出也是税前支付的，所以所得税率的变化不影响这个比率。税率只影响净利润。                                         |
| g      | 计提法定盈余公积             | 不变     | 这是净利润分配的事情，发生在EBIT和利息支出确定之后，不影响倍数。                                                       |
| h      | 宣告并支付股利              | 不变     | 这也是净利润分配的事情，不影响倍数。                                                                       |

总结影响因素 (利润表逻辑)：

可以把利润表的计算过程想象成一条流水线：

营业收入 → - 营业成本、经营费用 → EBIT (息税前利润) → - 费用化利息 → 利润总额 (税前利润) → - 所得税 → 净利润 → 利润分配 (计提公积、付股利)

- 利息保障倍数 = EBIT / 总利息支出。
- **分界线**：在计算出EBIT和确定总利息支出（通常由借款合同决定）之后，利息保障倍数就基本确定了。
- **线之前的事项** (影响EBIT或总利息支出的)：会影响倍数 (如abcd)。
- **线之后的事项** (如所得税、利润分配)：不会影响倍数 (如fgh)。
- **会计处理选择不影响实际支付和EBIT** (如e)。

## 1.10 现金流量利息保障倍数 (Cash Flow Interest Coverage Ratio)

### 1.10.1 通俗概括：

这个比率和上面的利息保障倍数很像，但是把分子换成了公司实际经营活动中收到的净现金，用更实在的“现金”这把伞去保护“利息”这个人，所以更靠谱。

- **公式**： 现金流量利息保障倍数=利息支出 (总额)经营活动产生的现金流量净额 (OCF)​
- **与利息保障倍数的比较**：
    - **分母相同**：都是**利息支出总额** (包括费用化和资本化利息)。“人还是那个人”。
    - **分子不同**：“伞换了一把更好的伞”。
        - 利息保障倍数分子：EBIT (权责发生制的利润)。
        - 现金流量利息保障倍数分子：经营活动现金流量净额 (收付实现制的现金)。
- **优点**：更加可靠。
    - 企业实际偿还利息用的是**真金白银的现金**，而不是账面上的会计利润 (EBIT可能包含很多尚未收到现金的收入或已支付现金的费用调整)。
    - 用实际的经营现金流入来衡量对利息的保障程度，比用会计收益衡量更稳健、更直接。

这个比率内容较少，理解其与利息保障倍数的区别和优点即可。

## 1.11 现金流量债务比 (Cash Flow to Debt Ratio)

### 1.11.1 通俗概括：

这个比率是看公司一年经营活动赚来的净现金，够不够偿还它全部的债务（短期+长期），或者说，需要多少年才能用经营现金还清所有债。

这个比率比较特殊，是“流量除以存量”。

- **公式**： 现金流量债务比=债务总额 (期末数)经营活动产生的现金流量净额 (OCF)​
- **与现金流量利息保障倍数的比较**：
    - **分子相同**：都是**经营活动现金流量净额**。“还是那把伞”。
    - **分母不同**：“伞底下的人换了一个人”。
        - 现金流量利息保障倍数分母：利息支出 (只保障利息)。
        - 现金流量债务比分母：**债务总额** (包括短期和长期负债，要保障全部本金)。
- **分母取值口径**：
    - 虽然是流量/存量，但分母“债务总额”通常取**期末数**，不取平均数。
    - **原因**：衡量偿债能力，关注的是期末实实在在还有多少债没还。
- **解读**：
    - 表明企业用其年度经营现金净流量偿还**全部债务**的能力。
    - **正向指标**：比率越高，说明用经营现金流覆盖全部债务的能力越强，或者说需要的时间越短。
    - **例子**：如果比率是 0.2，可以粗略理解为，如果债务不再增加且每年经营现金流保持不变，大约需要 1/0.2=5 年才能还清所有债务。

## 1.13 四个“现金开头”比率的专题总结

### 1.13.1 通俗概括：

我们学了好几个名字里带“现金”的比率，这里把它们放一起比较下，搞清楚分子分母都是啥，为啥这么算，它们共同的优点是啥。

这四个比率是复习中的薄弱环节和易混点。

**短期偿债能力中的“现金开头”比率 (分母都是流动负债)**：

1. **现金比率** = 流动负债现金资产 (货币资金)​
2. **现金流量比率** = 流动负债经营现金流量净额​

长期偿债能力中的“现金开头”比率 (分子都是经营现金流量净额)：

3. 现金流量利息保障倍数 = 利息支出经营现金流量净额​

4. 现金流量债务比 = 债务总额经营现金流量净额​

### 1.13.2 分子规律

- 如果比率名称是“**现金**XX比率”（两个字开头）：
    - 分子是资产负债表上的**存量指标**：**现金资产 (即货币资金)**，是静态的。
- 如果比率名称是“**现金流量**XX比率”（四个字开头）：
    - 分子是现金流量表上的**流量指标**：**经营活动产生的现金流量净额**，是动态的。
- **为什么都偏爱“经营活动”现金流量净额？**
    - **经营现金流**：来自企业日常、核心、可持续的经营活动，代表企业自身的“造血”能力，是银行评估还款的第一来源。
    - **投资活动现金流入**：通常来自变卖长期资产（“砸锅卖铁”），不可持续，是第二还款来源。
    - **筹资活动现金流入**：来自借新债或股东投入（“外部输血”），依赖外部，不是自身创造。

### 1.13.3 分母规律

- **短期偿债能力**的现金开头比率：
    - 名称中未体现分母，但因为是短期偿债，所以分母自然是**流动负债**。
- **长期偿债能力**的现金开头比率：
    - 名称中已体现分母：
        - “利息保障倍数” → 分母是**利息支出**。
        - “债务比” → 分母是**债务总额**。
- **流量/存量型偿债能力比率的分母取值**：
    - 现金流量比率 (短期) 和 现金流量债务比 (长期) 的分母（流动负债、债务总额）都是存量，但都取**期末数**，不取平均数。

### 1.13.4 共同特点

- 所有这些“现金开头”的财务比率，在衡量偿债能力时都**更加可靠**。
- 因为它们使用的是**真金白银的现金**或**实际发生的现金流量**，比使用非现金资产（如应收账款）或权责发生制的会计收益（如EBIT）来评估更为稳健和直接。

## 1.14 数字游戏题示例 (综合应用)

**题目**：已知某公司资产负债率 50%，长期资本负债率 40%，现金流量比率 (经营现金流/流动负债) 1.5。求现金流量债务比 (经营现金流/总负债) 是多少？

**思路**：又是数字游戏，题干全是相对数（比率），没有绝对数。我们可以自己设一个绝对数。

1. **设总资产 = 60** (选60是因为它有很多因数，方便计算，避免过多小数。你也可以设100，但可能计算略麻烦)。
2. **根据资产负债率 = 50%**：
    - 总负债 = 总资产 ×50%=60×0.5=30。
    - 所有者权益 = 总资产 - 总负债 = 60−30=30。
3. **根据长期资本负债率 = 40%**：
    - 长期资本负债率 = 长期负债 / (长期负债 + 所有者权益) = 0.4。
    - 设长期负债为 LTD。则：LTD / (LTD + 30) = 0.4。
    - LTD = 0.4× LTD + 0.4×30
    - 0.6× LTD = 12
    - 长期负债 (LTD) = 12/0.6=20。
    - (或者理解为：长期资本中，长期负债占40%，则所有者权益占60%。已知权益是30，它占60%，所以长期负债占40%，金额为 30×(40/60)=20。)
    - 长期资本 = 长期负债 + 所有者权益 = 20+30=50。
4. **计算流动负债**：
    - 流动负债 = 总负债 - 长期负债 = 30−20=10。
5. **根据现金流量比率 = 1.5**：
    - 经营现金流量净额 / 流动负债 = 1.5。
    - 经营现金流量净额 = 1.5× 流动负债 = 1.5×10=15。
6. **计算现金流量债务比**：
    - 现金流量债务比 = 经营现金流量净额 / 总负债
    - 现金流量债务比 = 15/30=0.5。
