
# 1 课程：投资决策进阶——深入理解内含收益率 (IRR)

> **课程回顾与引言：** 在之前的学习中（可能是指PPT或前序课程），我们接触了净现值 (NPV) 的概念。今天，我们来学习另一个非常重要的投资决策评价指标——**内含收益率 (Internal Rate of Return, IRR)**。

## 1.1 第一章：什么是内含收益率 (IRR)？

### 1.1.1 内含收益率的定义

> **通俗概括：** 内含收益率 (IRR) 就是一个能让项目的“总收入的现值”正好等于“总投入的现值”的那个“神奇的折扣率”。换句话说，在这个折扣率下，项目算出来的净现值 (NPV) 刚好是零。它反映的是项目本身能达到的收益水平。

- **核心概念：** 内含收益率是一个**折现率**。
- **关键特征：** 在这个特定的折现率 (IRR) 下，项目的净现值 (NPV) 等于零。
    - 回忆一下净现值的公式： NPV=未来现金流入的现值之和−初始投资的现值
    - 当 NPV = 0 时，就意味着： 未来现金流入的现值之和=初始投资的现值
    - 这个使得等式成立的折现率，就是我们所说的**内含收益率 (IRR)**。

### 1.1.2 为什么要计算内含收益率？

> **通俗概括：** 我们想知道这个项目本身到底有多“能打”（赚钱能力有多强），IRR 就是衡量这种内在赚钱能力的一个指标。

- IRR可以告诉我们一个投资项目其本身能够产生的回报率是多少，而不依赖于外部设定的某个资本成本或要求的最低收益率（虽然最终决策时会与之比较）。

## 1.2 第二章：如何计算内含收益率 (IRR)？—— 逐步测试法与插值法

> **通俗概括：** 算IRR有点像猜数字，我们得试几个不同的“折扣率”，看看哪个能让项目的净现值接近零。如果每年流入的现金一样多，有个简便方法；如果不一样，就得靠“试算”和“插值法”这个数学小技巧了。

计算IRR通常不像计算NPV那样直接代入公式就能出结果，它往往需要一个“求解”的过程。

### 1.2.1 特殊情况：每年现金净流量 (NCF) 相等（普通年金形式）

> **通俗概括：** 如果项目投产后，每年赚到的净现金都一样多（就像每年领固定的养老金一样），那算IRR会简单一些。

- **适用条件：**
    1. 原始投资额在第0期一次性投入。
    2. 投产后至项目结束，各年的现金净流量 (NCF) 都相等，形成一个**普通年金**。
- **计算步骤：**
    1. **利用 NPV=0 的原理：** 当 NPV = 0 时，我们有： 初始投资额=未来各年相等NCF的现值之和 因为未来各年NCF相等，所以未来NCF的现值之和可以表示为： 未来各年相等NCF的现值之和=每年NCF×年金现值系数(P/A,IRR,n) 其中：
        - P/A 代表年金现值系数的符号。
        - IRR 是我们要求解的内含收益率。
        - n 是年金的期数（即项目产生现金流的年数）。
    2. **推导出年金现值系数的计算公式：** 年金现值系数(P/A,IRR,n)=每年NCF初始投资额​
    3. **查表与插值：**
        - 根据上一步计算出的“年金现值系数”的值和已知的期数 n，去查**年金现值系数表**。
        - 找到与我们计算出的系数值最接近的两个利率。IRR就会落在这两个利率之间。
        - 然后使用**线性插值法 (Linear Interpolation)** 来估算IRR的精确值。

#### 1.2.1.1 **示例：某公司购置生产设备的IRR计算**

- **已知条件：**
    - 初始投资额 (固定资产投资) = 160万元 (这是在第0期流出)
    - 预计使用年限 (项目寿命期) = 10年
    - 使用期满后，预计净残值为 0元。
    - 预计每年产生的现金净流量 (NCF) = 30万元 (每年都相等)
    - 该公司要求的最低收益率 (投资者要求的，也叫资本成本或基准收益率) = 12% (这个是用来**对比**的，不是用来直接算IRR的)
- **求解内含收益率 (IRR)：**
    1. 计算年金现值系数：
        
        年金现值系数(P/A,IRR,10年)=30万元/年160万元​≈5.3333
        
    2. 查年金现值系数表 (n=10期)：
        
        我们需要在表中找到当 n=10 时，哪个利率对应的年金现值系数接近 5.3333。
        
        （讲者在音频中提到，通过查表发现这个值位于 13% 和 14% 两个利率之间对应的系数值之间。我们假设查表得到：）

    3. 使用线性插值法计算IRR：

        公式可以表示为：

### 1.2.2 一般情况：每年现金净流量 (NCF) 不相等

> **通俗概括：** 如果项目每年赚到的净现金不一样多，那就不能用上面的简便方法了，得老老实实地去“试”不同的折扣率，直到找到那个让净现值接近零的。

- **方法：** 逐步测试法 (Trial and Error) 结合线性插值法。
    1. **估计一个初始的折现率 (r1​)。**
    2. **用这个 r1​ 计算项目的净现值 (NPV1​)。** NPV1​=∑(1+r1​)tNCFt​​−初始投资
    3. **分析 NPV1​ 的结果：**
        - 如果 NPV1​ 接近零，那么 r1​ 就很接近IRR。
        - 如果 NPV1​>0，说明我们用的折现率 r1​ 太低了（折现不足），IRR 应该比 r1​ 高。我们需要尝试一个更高的折现率 r2​。
        - 如果 NPV1​<0，说明我们用的折现率 r1​ 太高了（折现过度），IRR 应该比 r1​ 低。我们需要尝试一个更低的折现率 r2​。
    4. **用新的折现率 r2​ 计算净现值 NPV2​。**
    5. **目标是找到两个折现率 r1​ 和 r2​，使得它们对应的 NPV1​ 和 NPV2​ 一个为正，一个为负** (这样零就夹在中间了)。
    6. **使用线性插值法估算IRR：** IRR≈r1​+(r2​−r1​)×NPV1​−NPV2​NPV1​​ (注意：这里假设 NPV1​ 是正值，NPV2​ 是负值。如果相反，公式中 NPV1​−NPV2​ 的绝对值仍然是两个NPV绝对值之和。)

## 1.3 第三章：如何运用内含收益率 (IRR) 进行投资决策？

> **通俗概括：** 算出来项目本身的“赚钱能力”(IRR) 后，我们还要看它有没有达到我们“最低的期望要求”（比如公司要求的最低收益率）。达到了才考虑做，没达到就不行。

- **决策标准：** 将计算出的项目的内含收益率 (IRR) 与投资者要求的最低收益率（或公司的资本成本、基准收益率，设为 k）进行比较。
    
    - **如果 IRR > k：** 项目可行。这意味着项目本身的预计回报率高于投资者要求的最低回报率，项目能赚钱。
    - **如果 IRR < k：** 项目不可行。项目本身的预计回报率低于要求，不值得投资。
    - **如果 IRR = k：** 项目处于临界点，理论上也可接受，但通常会寻求更高回报。
- **示例回顾：**
    
    - 假设我们计算出的设备投资项目 IRR 是 13.46%。
    - 公司要求的最低收益率是 12%。
    - 因为 13.46%>12%，所以这个项目从IRR的角度来看是**可行**的。

---

学习内含收益率的关键在于理解其定义（使NPV=0的折现率）以及掌握在不同现金流情况下的计算方法（特别是插值法的应用）。它为我们提供了一个衡量项目盈利能力的重要视角。
