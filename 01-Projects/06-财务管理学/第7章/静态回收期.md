
# 1 课程：投资决策基础——投资回收期 (Payback Period)

> **课程目标：** 今天我们主要学习以下几个内容：
> 
> 1. 了解投资回收期的含义。
> 2. 掌握不同情况下投资回收期的计算方法。
> 3. 学习如何使用投资回收期进行投资决策。
> 4. 探讨投资回收期的优缺点（虽然本次讲解未深入，但这是完整学习应包含的）。

## 1.1 第一章：什么是投资回收期？

### 1.1.1 投资回收期的含义

> **通俗概括：** 投资回收期，说白了就是“回本儿要多久？” 也就是你投出去的钱，需要多长时间才能通过项目赚的钱全部收回来。

- **定义：** 投资回收期是指投资项目从投产后（或从投资开始）所产生的累计现金净流量与原始投资额相等时所需要的时间。
- **核心思想：** 衡量的是收回初始投资的速度。
- **与货币时间价值的关系：**
    - **不考虑货币时间价值的回收期（本次主要讲解的）：** 直接用未来的现金流量累计，看何时与初始投资相等。
    - **考虑货币时间价值的回收期（也叫折现回收期）：** 是将未来的现金流量先折现到初始时点，再进行累计比较。本次讲解的例子主要侧重于不考虑货币时间价值的情况。

## 1.2 第二章：如何计算投资回收期？

> **通俗概括：** 算“回本儿时间”主要看每年赚的钱是不是一样多。如果一样多，就简单除一下；如果不一样多，就得一年一年地加起来看。

### 1.2.1 情况一：未来每年现金净流量相等

> **通俗概括：** 如果项目每年赚的净现金都一样多，那么用总投资除以每年赚的钱，就知道几年能回本了。

- **适用条件：** 项目投产后，每年的现金净流量 (NCF) 都相同。
- **计算公式：** 投资回收期=每年相等的现金净流量原始投资额​
- **示例：**
    - 假设初始投资额为 20万元。
    - 每年产生的现金净流量为 5万元。
    - **投资回收期** = 5万元/年20万元​=4年。
    - 这意味着，需要4年的时间，通过每年赚的5万元，才能把最初投的20万元全部收回来。

### 1.2.2 情况二：未来每年现金净流量不相等

> **通俗概括：** 如果项目每年赚的净现金有多有少，我们就得一笔一笔地加，看看加到什么时候刚好把本钱都收回来。如果某一年没完全收回，但下一年又超了，那就要算算具体是那一年的几分之几的时候回本的。

- **适用条件：** 项目投产后，每年的现金净流量 (NCF) 不相同。
- **计算方法：** 逐年累计现金净流量，直到累计数额等于或超过原始投资额。
    1. 计算截至各年末的累计现金净流量。
    2. 确定原始投资额在哪一年内被完全收回。
    3. 如果恰好在某年末完全收回，则该年数即为回收期。
    4. 如果在某一年内（非年末）收回，则回收期的计算公式为： 投资回收期=尚未收回投资额的上一年的年数+完全收回投资的当年的现金净流量尚未收回的投资额​ 其中，“尚未收回的投资额”是指截至上一年度末，还差多少钱没有收回。

#### 1.2.2.1 **示例：项目A和项目B的回收期计算（假设要求两年内回本）**

**项目A：**

- 原始投资额（第0年流出）：7,500元
    
- 第1年年末现金净流入：4,000元
    
- 第2年年末现金净流入：3,500元
    
- 第3年年末现金净流入：... (后续数据对前两年回收不重要)
    
- **计算过程：**
    
    1. **第1年年末：**
        - 累计现金净流入 = 4,000元。
        - 尚未收回投资 = 7,500−4,000=3,500元。 (此时还未回本)
    2. **第2年年末：**
        - 当年现金净流入 = 3,500元。
        - 累计现金净流入 = 第1年累计 4,000元 + 第2年 3,500元 = 7,500元。
        - 截至第2年年末，累计现金净流入正好等于原始投资额 7,500元。
    
    - **项目A的投资回收期 = 2年。**

**项目B：**

- 原始投资额（第0年流出）：5,000元
    
- 第1年年末现金净流入：2,500元
    
- 第2年年末现金净流入：1,200元
    
- 第3年年末现金净流入：3,000元 (这一整年预计产生这么多)
    
- 第4年年末现金净流入：...
    
- **计算过程：**
    
    1. **第1年年末：**
        - 累计现金净流入 = 2,500元。
        - 尚未收回投资 = 5,000−2,500=2,500元。 (还未回本)
    2. **第2年年末：**
        - 当年现金净流入 = 1,200元。
        - 累计现金净流入 = 第1年累计 2,500元 + 第2年 1,200元 = 3,700元。
        - 尚未收回投资 = 5,000−3,700=1,300元。 (到第2年年末，仍然没有完全回本，还差1,300元)
    3. **第3年内回本：**
        - 我们知道到第2年末还差1,300元才能回本。
        - 第3年一整年预计能产生3,000元的现金净流入。
        - 那么，收回这剩下的1,300元，在第3年需要的时间是： 第3年的现金净流量 (3000元)尚未收回的投资额 (1300元)​≈0.4333年
    
    - **项目B的投资回收期** = 2年+0.4333年≈2.43年。

## 1.3 第三章：如何使用投资回收期进行投资决策？

> **通俗概括：** 当然是选回本儿快的项目啦！如果公司有规定几年内必须回本，那达不到要求的项目就不考虑了。

- **决策标准：**
    
    1. **与设定的标准回收期比较：** 企业通常会根据自身情况或行业标准设定一个可接受的最长回收期。如果项目的计算回收期小于或等于标准回收期，则项目初步可行。
    2. **比较不同方案：** 在多个备选方案中，通常选择投资回收期较短的方案。因为回收期越短，意味着投资风险相对较小，资金回笼快。
- **示例决策：**
    
    - 项目A的回收期是2年。
    - 项目B的回收期约是2.43年。
    - 假设公司要求的标准回收期是2年。
    - **结论：**
        - 项目A (2年) 符合标准回收期。
        - 项目B (2.43年) 不符合标准回收期（如果标准是严格的2年）。
        - 如果是在A和B之间选择，并且都符合标准回收期或者没有标准回收期，那么因为项目A的回收期 (2年) 短于项目B的回收期 (2.43年)，所以会**优先选择项目A**。

## 1.4 第四章：投资回收期的优缺点（简要提及）

> **通俗概括：** “回本儿时间”这个指标简单好懂，能看出风险大小，但它也有毛病，就是没考虑钱放久了会贬值，也没看回本儿之后还能赚多少。

本次讲解主要集中在含义和计算，但了解其优缺点对于全面评估很重要：

- **优点：**
    - 计算简单，易于理解。
    - 能够一定程度上反映项目的流动性和投资风险（回收期越短，流动性越好，风险相对越小）。
- **缺点：**
    - **没有考虑货币的时间价值：** 这是其最主要的缺陷，它把不同年份收到的现金看得同等重要。
    - **忽略了回收期满后的现金流量：** 一个项目可能回收期较长，但回收期后的收益非常可观；另一个项目可能回收期短，但后续收益很少。回收期法无法区分这种情况。
    - 可能导致企业过于注重短期利益，而放弃一些具有长期战略意义但回收期较长的项目。

因此，投资回收期通常作为一种辅助的决策方法，尤其在企业资金紧张或项目风险较高时，会比较关注。在做最终决策时，还需要结合净现值 (NPV)、内含收益率 (IRR) 等考虑了货币时间价值的指标进行综合评估。
