# 1 课程：投资决策指标探秘——现值指数 (PI)

> **课程目标：** 今天我们主要学习以下几个内容：
> 
> 1. 了解现值指数的含义。
> 2. 掌握现值指数的计算公式。
> 3. 了解现值指数与净现值 (NPV) 的关系公式。
> 4. 学习如何使用现值指数进行投资决策。
> 5. 探讨现值指数的优缺点。

## 1.1 第一章：什么是现值指数 (PI)？

### 1.1.1 现值指数的含义与简称

> **通俗概括：** 现值指数 (PI) 就是衡量你投入的每一块钱，将来能收回多少“现值”的一个比例。它告诉你这个投资项目“划不划算”的程度。

- **简称：** PI (Profitability Index)
    - P = Profitability (盈利能力)
    - I = Index (指数)
- **定义：** 现值指数是指一个投资项目**未来现金净流入的总现值**与**原始投资额的现值**之比。
    - **关键词：** “比”、“指数”。这说明它是一个相对数，而不是一个绝对金额。

### 1.1.2 现值指数的计算公式

> **通俗概括：** 算PI，就是用项目未来所有能收到的钱（都折算到今天）去除以项目一开始所有投出去的钱（也折算到今天）。

- **基本公式：** PI=原始投资额的现值未来现金净流入的总现值​
    - **未来现金净流入的总现值：** 指的是项目在运营期间及终结期产生的各期现金净流量 (NCF)，按照一定的折现率（通常是资本成本或要求的最低报酬率）折算到第0期（即投资初期）的价值总和。
    - **原始投资额的现值：** 指的是项目在投资期发生的各种现金流出（如购买设备、垫支营运资金等），同样折算到第0期的价值总和。如果所有投资都在第0期一次性投入，那么其现值就是其本身。

## 1.2 第二章：现值指数 (PI) 与净现值 (NPV) 的关系

> **通俗概括：** PI 和 NPV 其实是“亲戚”，PI 可以通过 NPV 变个形算出来，它们都反映了项目赚不赚钱，只是角度不同。

### 1.2.1 从NPV公式推导PI公式

- **回顾NPV公式：** NPV=未来现金净流入的总现值−原始投资额的现值
- **变形：** 我们可以把“未来现金净流入的总现值”从NPV公式中表示出来： 未来现金净流入的总现值=NPV+原始投资额的现值
- **代入PI公式：** 将上面这个关系代入PI的基本公式的分子部分： PI=原始投资额的现值NPV+原始投资额的现值​
- **进一步分离：** 这个分数可以拆分成两部分： PI=原始投资额的现值NPV​+原始投资额的现值原始投资额的现值​ 简化后得到： PI=原始投资额的现值NPV​+1 或者写成： PI=1+原始投资额的现值NPV​
- **重要关系：** 这个公式揭示了PI和NPV之间的直接联系。

## 1.3 第三章：如何使用现值指数 (PI) 进行投资决策？

> **通俗概括：** 看PI值大不大。如果PI大于1，说明投一块钱能收回一块多（现值），项目就划算；如果小于1，就不划算。

### 1.3.1 决策规则

- **如果 PI > 1：** 项目可行。
    - **原因：** PI > 1 意味着“未来现金净流入的总现值” > “原始投资额的现值”。这与 NPV > 0 的判断标准是一致的。说明项目在收回全部投资（现值）后，还能产生额外的正收益（现值）。这表示项目的盈利能力超过了投资者要求的最低报酬水平。
- **如果 PI < 1：** 项目不可行。
    - **原因：** PI < 1 意味着“未来现金净流入的总现值” < “原始投资额的现值”。这与 NPV < 0 的判断标准是一致的。说明项目未来产生的现金流入（折现后）不足以弥补初始投资（折现后），项目是亏损的。
- **如果 PI = 1：** 项目处于盈亏平衡点（以现值衡量）。
    - **原因：** PI = 1 意味着“未来现金净流入的总现值” = “原始投资额的现值”。这与 NPV = 0 的判断标准是一致的。项目刚好能收回投资的现值，没有额外的超额收益，但也没有亏损。

### 1.3.2 PI与NPV决策的一致性

从上面的推导关系 `PI = 1 + NPV / 原始投资额的现值` 可以看出：

- 当 NPV > 0 时，NPV / 原始投资额的现值 > 0，所以 PI > 1。
- 当 NPV < 0 时，NPV / 原始投资额的现值 < 0，所以 PI < 1 (如果NPV的绝对值小于原始投资额的现值)。
- 当 NPV = 0 时，NPV / 原始投资额的现值 = 0，所以 PI = 1。 因此，对于单个独立项目的接受与否决策，PI法和NPV法得出的结论通常是一致的。

## 1.4 第四章：现值指数 (PI) 的优缺点与应用场景

### 1.4.1 现值指数的优点

> **通俗概括：** PI的好处是它能看出“投入产出比”，特别适合比较那些大小不一样的独立项目哪个更“有效率”。

- **可以用于独立投资方案获利能力的比较：**
    - PI是一个**相对数**，它反映的是投资的**效率**（即每单位投资现值能带来多少未来现金流入的现值）。
    - 而NPV是一个**绝对数**，它反映的是投资的**效益**（即项目能带来的总的净现值收益）。
- **适用于原始投资额不同的独立项目比较：** 当比较几个初始投资额不同的独立项目时，如果仅仅看NPV的绝对值，可能会偏向于投资规模大的项目（即使其效率不高）。而PI可以更好地衡量哪个项目的投资效率更高。

#### 1.4.1.1 **示例：比较方案A和方案B**

假设有两个投资方案A和B，相关数据如下：

- **方案A：**
    
    - 原始投资额的现值 = 30,000元
    - 未来现金净流入的总现值 = 31,500元
    - NPV = 31,500−30,000=1,500元
- **方案B：**
    
    - 原始投资额的现值 = 3,000元
    - 未来现金净流入的总现值 = 4,200元
    - NPV = 4,200−3,000=1,200元
- **如果只看NPV：** 方案A的NPV (1,500元) 大于方案B的NPV (1,200元)，似乎方案A更好。
    
- **计算现值指数PI：**
    
    - **方案A的PI：** PIA​=30,00031,500​=1.05 这意味着方案A每投资1元（现值），可以收回1.05元（现值）。
    - **方案B的PI：** PIB​=3,0004,200​=1.40 这意味着方案B每投资1元（现值），可以收回1.40元（现值）。
- **根据PI比较：** 方案B的PI (1.40) 大于方案A的PI (1.05)，说明方案B的投资效率更高。如果我们是在有限资金下选择互斥方案或者进行项目排序，PI提供了重要的参考。
    

### 1.4.2 现值指数的缺点

> **通俗概括：** PI只看效率，不看总盘子大小。有时候效率高的项目可能赚的总钱数反而少，而且它也没法完全看出一个项目啥时候能回本。

- **不能完全反映项目的综合经济效益：**
    - PI只关注投资效率，即单位投资能带来的回报。它不能直接告诉我们项目能带来的绝对财富增加量 (这方面NPV更直观)。
    - **例子：** 接上例，虽然方案B效率高 (PI=1.40)，但它带来的总净现值是1,200元；而方案A效率稍低 (PI=1.05)，但带来的总净现值是1,500元。如果目标是最大化总财富，且资金充足，可能会选择方案A。
- **可能无法完全反映项目现金流量的时间分布：** 虽然计算PI时已经考虑了现金流量的现值，但PI本身是一个汇总的比率，不能详细展示现金流在项目各年的具体回收情况。
- **对于互斥项目决策的局限性：** 在选择互斥项目（即几个项目中只能选一个）时，如果项目的投资规模差异很大，单纯依据PI大小来决策可能会导致选择了一个总收益（NPV）较小的方案。在这种情况下，NPV通常是更优先的决策标准。

### 1.4.3 总结

- **现值指数 (PI)** 是一个有用的辅助决策指标，尤其在比较不同规模的独立项目或在有资本限额时对项目进行排序时。
- 它本身不是一个完美的指标，需要结合NPV等其他指标以及具体情况综合判断。
- **考试中：** 如果题目要求计算现值指数，或者在特定情境下（如独立方案比较）需要用到，那么就需要掌握其计算和决策规则。
