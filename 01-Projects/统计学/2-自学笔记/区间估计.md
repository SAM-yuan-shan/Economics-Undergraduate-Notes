## 一、区间估计 (Interval Estimation)
区间估计的通俗解释：猜一个精确的数值容易出错，所以我们猜一个区间来提高准确性。
- **例子**：猜一位女士的年龄。如果猜30岁，很容易猜错。但如果猜她在25到30岁之间，相对来说就更靠谱。
### 1.1 点估计 vs 区间估计
假设叶老师粉丝的年龄服从正态分布 $$N(\theta, \sigma^2)$$，其中 $$\sigma^2$$已知，$$\theta$$（即均值$$\mu$$）未知，需要估计 $$\theta$$。
- **点估计 (Point Estimation)**：
    1. 抽样。
    2. 对样本进行矩估计或最大似然估计。
    3. 得出一个估计值（例如，平均年龄是23岁）。
    - **缺点**：可靠性有限，容易出错。
- **区间估计 (Interval Estimation)**：
    - 为了增加可靠性，我们不说平均年龄是23岁，而是说平均年龄在20到25岁之间。
    - 这样做，可靠性就增加了。
### 1.2 区间估计研究的两个核心问题
1.  **可靠性 (Reliability)**：首先要确保估计是可靠的。如果估计结果不可靠（例如，估计平均年龄80岁），则没有意义。
2.  **精度 (Precision)**：在可靠的前提下，我们希望估计的区间尽可能小。
    - 例如，估计年龄在0到100岁之间，虽然非常可靠，但精度太差。
- **目标**：在确保可靠性的前提下，使我们估计出来的区间尽可能地小。
### 1.3 核心概念
- **犯错率 (Error Rate) / 显著性水平 (Significance Level)**：用 $$\alpha$$ 表示。
    - 例如，允许犯错的概率是5% ($$\alpha = 0.05$$)。
- **置信度 (Confidence Level)**：用 $$1-\alpha$$ 表示。
    - 对应的，估计正确的概率是95% ($$1-\alpha = 0.95$$)。
- **置信区间 (Confidence Interval)**：
    - 我们估计的区间，例如[20, 23]。真实的参数 $$\theta$$（例如粉丝平均年龄）落在这个区间[20, 23]中的概率是 $$1-\alpha$$（例如95%）。
    - 即 $$P(\text{真实参数 } \theta \in [\text{估计下限, 估计上限}]) = 1-\alpha$$
### 1.4 如何求置信区间：枢轴变量法 (Pivotal Quantity Method)
- **枢轴变量**：寻找一个其分布不依赖于未知参数的函数（通常涉及样本和未知参数）。
- 需要熟悉第六章中学习的单正态总体下的四种常用抽样分布。
#### 1.4.1 Case 1: $$\sigma^2$$已知，估计总体均值$$\mu$$
- **枢轴变量**:
  $$Y = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1)$$  (其中$$\bar{X}$$ 是样本均值，$$n$$ 是样本容量，$$\sigma$$ 是总体标准差)
- **目标**: 求一个区间 $$[\theta_1, \theta_2]$$使得$$P(\theta_1 \le \mu \le \theta_2) = 1-\alpha$$。
- **推导**:
  根据标准正态分布的性质，我们有：
  $$P\left(-U_{\frac{\alpha}{2}} \le \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \le U_{\frac{\alpha}{2}}\right) = 1-\alpha$$  其中$$U_{\frac{\alpha}{2}}$$是标准正态分布的上$$\frac{\alpha}{2}$$分位数，满足$$P(Y > U_{\frac{\alpha}{2}}) = \frac{\alpha}{2}$$。
  选择对称区间 $$[-U_{\frac{\alpha}{2}}, U_{\frac{\alpha}{2}}]$$的原因：在概率$$1-\alpha$$ 确定的前提下，对称区间的长度最短，即精度最高。
- 整理上述不等式，得到 $$\mu$$ 的置信区间：
  $$P\left(\bar{X} - U_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}} \le \mu \le \bar{X} + U_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}}\right) = 1-\alpha$$  所以，$$\mu$$ 的$$1-\alpha$$ 置信区间为：
  $$\left[\bar{X} - U_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}}, \bar{X} + U_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}}\right]$$
#### 1.4.2 Case 2: $$\sigma^2$$未知，估计总体均值$$\mu$$
- **枢轴变量**:
  $$Y = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$$  (其中$$S$$是样本标准差，$$t(n-1)$$ 表示自由度为$$n-1$$ 的t分布)
- **推导**:
  $$P\left(-t_{\frac{\alpha}{2}}(n-1) \le \frac{\bar{X} - \mu}{S/\sqrt{n}} \le t_{\frac{\alpha}{2}}(n-1)\right) = 1-\alpha$$  其中$$t_{\frac{\alpha}{2}}(n-1)$$是t分布的上$$\frac{\alpha}{2}$$ 分位数。
- $$\mu$$的$$1-\alpha$$ 置信区间为：
  $$\left[\bar{X} - t_{\frac{\alpha}{2}}(n-1)\frac{S}{\sqrt{n}}, \bar{X} + t_{\frac{\alpha}{2}}(n-1)\frac{S}{\sqrt{n}}\right]$$
#### 1.4.3 Case 3: 估计总体方差 $$\sigma^2$$-   **情形一: 总体均值$$\mu$$ 已知**
    -   **枢轴变量**:
        $$Y = \sum_{i=1}^{n} \frac{(X_i - \mu)^2}{\sigma^2} \sim \chi^2(n)$$        (其中$$\chi^2(n)$$表示自由度为$$n$$ 的卡方分布)
-   **情形二: 总体均值 $$\mu$$ 未知**
    -   **枢轴变量**:
        $$Y = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$        (其中$$S^2$$ 是样本方差)
    -   **目标**: 求区间 $$[\theta_1, \theta_2]$$使得$$P(\theta_1 \le \sigma^2 \le \theta_2) = 1-\alpha$$。
    -   卡方分布的图像是右偏的。我们找两个分位数，使得它们之间的面积为 $$1-\alpha$$:
        $$P\left(\chi^2_{1-\frac{\alpha}{2}}(n-1) \le \frac{(n-1)S^2}{\sigma^2} \le \chi^2_{\frac{\alpha}{2}}(n-1)\right) = 1-\alpha$$        其中$$\chi^2_{\frac{\alpha}{2}}(n-1)$$是卡方分布的上$$\frac{\alpha}{2}$$分位数，$$\chi^2_{1-\frac{\alpha}{2}}(n-1)$$ 是卡方分布的下$$\frac{\alpha}{2}$$分位数 (即上$$1-\frac{\alpha}{2}$$ 分位数)。
    -   整理得到 $$\sigma^2$$的$$1-\alpha$$ 置信区间为：
        $$\left[\frac{(n-1)S^2}{\chi^2_{\frac{\alpha}{2}}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\frac{\alpha}{2}}(n-1)}\right]$$    -   **注意**: 对于卡方分布，这样选取的两边各留$$\frac{\alpha}{2}$$ 面积的区间，不一定是最短的（即精度不一定是最高的）。但这是通常的做法，模仿正态分布的处理方式。
### 1.5 区间估计过程回顾
- 只要完整理解上述过程，就不需要死记硬背表格。
- **需要复习的背景知识**：
    1.  $$\alpha$$**分位数** (alpha quantile)：右侧面积为$$\alpha$$的点。双侧$$\alpha$$分位数则指右侧面积为$$\frac{\alpha}{2}$$ 的点。
    2.  **单正态总体下的四个抽样分布** (通常在教材第六章)。
## 二、假设检验 (Hypothesis Testing)
假设检验的通俗解释：我要看看你是不是在吹牛。
- **例子**：有个同学声称自己的投篮命中率能达到50%。
    - 我提出一个假设 $$H_0$$(原假设): 他的投篮命中率$$X \ge 50\%$$。
    - **抽样观察**:
        - 如果他投了10次，只中了1次。这时，我有理由怀疑他在吹牛，于是拒绝原假设 $$H_0$$。
        - 如果他投了10次，中了9次。这时，我没有理由怀疑他在吹牛，于是接受原假设 $$H_0$$。
### 2.1 假设检验全过程示例
- **场景**: 一家鲜榨果汁厂家声称他们的果汁每瓶都是500ml。已知这种果汁的体积 $$X$$服从正态分布$$N(\mu, \sigma^2)$$，其中标准差 $$\sigma=50$$ml (视频中提及，后面计算示例也基于此)，均值 $$\mu$$ 未知。我们要验证厂家的声称。
#### 2.1.1 第一步：提出假设
- **原假设 (Null Hypothesis)**，记为 $$H_0$$:
  $$H_0: \mu = 500\text{ml}$$ (即厂家的声称是对的)
- **备择假设 (Alternative Hypothesis)**，记为 $$H_1$$:
  $$H_1: \mu \ne 500\text{ml}$$ (即厂家的声称是错的，均值不是500ml)
#### 2.1.2 第二步：选择检验统计量 (Test Statistic)
- 我们需要根据抽取的样本来判断原假设的对错。
    - 比如，抽取 $$n=100$$ 瓶果汁作为样本。
    - 如果样本均值 $$\bar{X} = 300\text{ml}$$，这与声称的500ml偏离太大，我们倾向于拒绝 $$H_0$$。
    - 如果样本均值 $$\bar{X} = 499\text{ml}$$，这与500ml偏离较小，我们倾向于接受 $$H_0$$。
- **关键问题**: 偏离多小算“小”（接受 $$H_0$$）？偏离多大算“大”（拒绝 $$H_0$$）？需要确定一个临界值 $$C$$。
    - 通常比较 $$|\bar{X} - \mu_0|$$与某个值$$C$$ 的大小。
- **检验统计量的选择**：与区间估计中枢轴变量的选取方法类似。
  当 $$H_0$$为真时 (即$$\mu = \mu_0 = 500$$)，检验统计量为：
  $$Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} \sim N(0, 1)$$
#### 2.1.3 第三步：确定显著性水平 $$\alpha$$ 和理解两类错误
无论我们选择接受还是拒绝 $$H_0$$，都有可能犯错误。
- **第一类错误 (Type I Error / 弃真错误 / $$\alpha$$ 错误)**：
    - 定义：原假设 $$H_0$$本身是真的，但我们通过样本推断拒绝了$$H_0$$。
    - 例子：厂家果汁确实是平均500ml，但我们碰巧抽到的一批样本体积偏小，导致错误地拒绝了厂家的声称。
    - 犯第一类错误的概率记为 $$\alpha = P(\text{拒绝 } H_0 | H_0 \text{ 为真})$$。
- **第二类错误 (Type II Error / 取伪错误 / $$\beta$$ 错误)**：
    - 定义：原假设 $$H_0$$本身是假的，但我们通过样本推断接受了$$H_0$$。
    - 例子：厂家果汁实际平均不足500ml，但我们碰巧抽到的一批样本体积接近500ml，导致错误地接受了厂家的声称。
    - 犯第二类错误的概率记为 $$\beta = P(\text{接受 } H_0 | H_0 \text{ 为假})$$。
- **注意**: 当样本量 $$n$$固定时，$$\alpha$$ 和$$\beta$$不可能同时降低。（例如，扩大接受$$H_0$$的标准以降低$$\alpha$$，会导致 $$\beta$$ 增大）。
- **基本原则**: 控制犯第一类错误的概率，即“尽量不冤枉好人”（不轻易拒绝一个真实的原假设）。
    - 我们设定一个允许犯第一类错误的最大概率，这个概率就是**显著性水平 $$\alpha$$**。
    - 要求 $$P(\text{拒绝 } H_0 | H_0 \text{ 为真}) \le \alpha$$。通常取等号，即等于 $$\alpha$$。
#### 2.1.4 第四步：确定拒绝域 (Rejection Region)
- 犯第一类错误的最大概率为 $$\alpha$$，即 $$P(\text{拒绝 } H_0 | H_0 \text{ 为真}) = \alpha$$。
- 当样本均值 $$\bar{X}$$与假设的总体均值$$\mu_0$$偏离过大时，我们就拒绝$$H_0$$。这个“偏离过大”的区域就是拒绝域。
- 对于双侧检验 $$H_1: \mu \ne \mu_0$$，检验统计量 $$Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$$。
- 拒绝域由 $$|Z| \ge U_{\frac{\alpha}{2}}$$ 确定。
    - 即，如果计算得到的 $$Z$$值落在$$(-\infty, -U_{\frac{\alpha}{2}}] \cup [U_{\frac{\alpha}{2}}, +\infty)$$区间内，则拒绝$$H_0$$。
    - 如果 $$Z$$值落在$$(-U_{\frac{\alpha}{2}}, U_{\frac{\alpha}{2}})$$区间内，则接受$$H_0$$（或表述为“没有足够证据拒绝 $$H_0$$”）。
#### 2.1.5 第五步：根据样本观测值做出决策
- **示例**: 抽取 $$n=100$$瓶果汁，测得样本均值$$\bar{X} = 490\text{ml}$$。已知 $$\sigma=50\text{ml}$$，原假设 $$H_0: \mu = 500\text{ml}$$。设显著性水平 $$\alpha = 0.05$$。
- 查标准正态分布表，得到 $$U_{\frac{\alpha}{2}} = U_{0.025} = 1.96$$。
- 计算检验统计量的观测值 (observed value):
  $$Z_{obs} = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} = \frac{490 - 500}{50/\sqrt{100}} = \frac{-10}{50/10} = \frac{-10}{5} = -2$$
- **决策**:
  比较 $$|Z_{obs}|$$与$$U_{\frac{\alpha}{2}}$$:
  $$|Z_{obs}| = |-2| = 2$$  因为$$2 > 1.96$$，所以观测值 $$Z_{obs}$$ 落在了拒绝域内。
- **结论**: 在显著性水平 $$\alpha = 0.05$$下，拒绝原假设$$H_0$$。即认为厂家声称的平均500ml不属实。
- **换一个例子**: 如果样本均值 $$\bar{X} = 495\text{ml}$$ (其他条件不变)。
  $$Z_{obs} = \frac{495 - 500}{50/\sqrt{100}} = \frac{-5}{5} = -1$$ $$|Z_{obs}| = |-1| = 1$$  因为$$1 < 1.96$$，所以观测值 $$Z_{obs}$$ 落在了接受域内。
- **结论**: 在显著性水平 $$\alpha = 0.05$$下，接受原假设$$H_0$$(或者说，没有足够的证据拒绝$$H_0$$)。
### 2.2 假设检验的本质
- 首先假设 $$H_0$$ 是真的。
- 在这个前提下，我们一次抽样得到的样本均值与声称的总体均值 $$\mu_0$$偏离很远（即检验统计量的值落入拒绝域）是一个小概率事件（其发生的概率为$$\alpha$$）。
- 如果在一次抽样中，这个小概率事件真的发生了（即样本结果显示偏离很远），我们就有理由怀疑当初“$$H_0$$是真的”这个前提假设是有问题的，从而拒绝$$H_0$$。
### 2.3 假设检验的表格总结 (部分)
#### 2.3.1 单个正态总体均值 $$\mu$$ 的检验 ($$\sigma^2$$ 已知)
- **检验统计量**: $$Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$$(当$$H_0$$ 为真时，$$Z \sim N(0,1)$$)
    1.  **双侧检验**:
        -   $$H_0: \mu = \mu_0$$        -  $$H_1: \mu \ne \mu_0$$        -   **拒绝域**:$$|Z| \ge U_{\frac{\alpha}{2}}$$
    2.  **右单侧检验**:
        -   $$H_0: \mu \le \mu_0$$(或$$H_0: \mu = \mu_0$$)
        -   $$H_1: \mu > \mu_0$$        -   **拒绝域**:$$Z \ge U_{\alpha}$$(因为我们只关心$$\mu$$是否显著大于$$\mu_0$$)
    3.  **左单侧检验**:
        -   $$H_0: \mu \ge \mu_0$$(或$$H_0: \mu = \mu_0$$)
        -   $$H_1: \mu < \mu_0$$        -   **拒绝域**:$$Z \le -U_{\alpha}$$
#### 2.3.2 单个正态总体均值 $$\mu$$ 的检验 ($$\sigma^2$$ 未知)
- **检验统计量**: $$t = \frac{\bar{X} - \mu_0}{S/\sqrt{n}}$$(当$$H_0$$ 为真时，$$t \sim t(n-1)$$)
    1.  **双侧检验**:
        -   $$H_0: \mu = \mu_0$$        -  $$H_1: \mu \ne \mu_0$$        -   **拒绝域**:$$|t| \ge t_{\frac{\alpha}{2}}(n-1)$$
    2.  **右单侧检验**:
        -   $$H_0: \mu \le \mu_0$$        -  $$H_1: \mu > \mu_0$$        -   **拒绝域**:$$t \ge t_{\alpha}(n-1)$$
    3.  **左单侧检验**:
        -   $$H_0: \mu \ge \mu_0$$        -  $$H_1: \mu < \mu_0$$        -   **拒绝域**:$$t \le -t_{\alpha}(n-1)$$
#### 2.3.3 单个正态总体方差 $$\sigma^2$$ 的检验
-   **情形一: 均值 $$\mu$$ 已知**
    -   **检验统计量**: $$\chi^2 = \frac{\sum_{i=1}^{n}(X_i - \mu)^2}{\sigma_0^2}$$(当$$H_0: \sigma^2 = \sigma_0^2$$ 为真时，$$\chi^2 \sim \chi^2(n)$$)
    -   **双侧检验**:
        -   $$H_0: \sigma^2 = \sigma_0^2$$        -  $$H_1: \sigma^2 \ne \sigma_0^2$$        -   **拒绝域**:$$\chi^2 \le \chi^2_{1-\frac{\alpha}{2}}(n)$$或$$\chi^2 \ge \chi^2_{\frac{\alpha}{2}}(n)$$-   **情形二: 均值$$\mu$$ 未知**
    -   **检验统计量**: $$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2}$$(当$$H_0: \sigma^2 = \sigma_0^2$$ 为真时，$$\chi^2 \sim \chi^2(n-1)$$)
    -   **双侧检验**:
        -   $$H_0: \sigma^2 = \sigma_0^2$$        -  $$H_1: \sigma^2 \ne \sigma_0^2$$        -   **拒绝域**:$$\chi^2 \le \chi^2_{1-\frac{\alpha}{2}}(n-1)$$或$$\chi^2 \ge \chi^2_{\frac{\alpha}{2}}(n-1)$$    - (单侧检验的拒绝域类似地取在卡方分布的一侧，使得该侧面积为$$\alpha$$)
