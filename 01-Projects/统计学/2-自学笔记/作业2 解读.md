## 检验骰子是否均匀 (卡方拟合优度检验) 🎲

这个问题要求我们根据掷骰子60次的结果，在显著性水平 α=0.05 下检验骰子是否均匀。 我们将使用卡方拟合优度检验。

### 1. 假设：

- **零假设 (H0​)**: 骰子是均匀的 (即，掷出每个点数的概率为 1/6)。
- **备择假设 (H1​)**: 骰子不是均匀的。

### 2. 期望频数：

如果骰子是均匀的，我们期望每个点数出现的次数为 60×(1/6)=10 次。

### 3. 观测频数：

- 1: 7 次
- 2: 8 次
- 3: 12 次
- 4: 11 次
- 5: 9 次
- 6: 13 次

### 4. 计算卡方检验统计量 (χ2)：

卡方检验统计量的公式为：

χ2=∑Ei​(Oi​−Ei​)2​

其中 Oi​ 是观测频数，Ei​ 是期望频数。


|                  |                |                |               |                |                    |
| ---------------- | -------------- | -------------- | ------------- | -------------- | ------------------ |
| **点数 (Outcome)** | **观测频数 (Oi​)** | **期望频数 (Ei​)** | **(Oi​−Ei​)** | **(Oi​−Ei​)2** | **(Oi​−Ei​)2/Ei​** |
| 1                | 7              | 10             | -3            | 9              | 0.9                |
| 2                | 8              | 10             | -2            | 4              | 0.4                |
| 3                | 12             | 10             | 2             | 4              | 0.4                |
| 4                | 11             | 10             | 1             | 1              | 0.1                |
| 5                | 9              | 10             | -1            | 1              | 0.1                |
| 6                | 13             | 10             | 3             | 9              | 0.9                |
| **合计**           | **60**         | **60**         |               |                | **χ2=2.8**         |

### 5. 自由度 (df)：

df=k−1，其中 k 是分类数 (点数个数)。

df=6−1=5。

### 6. 临界值：

对于 α=0.05 和 df=5，从卡方分布表中查得的临界卡方值 (χ0.05,52​) 约为 11.070。

### 7. 决策：

由于计算得到的 χ2 值 (2.8) 小于临界值 (11.070)，我们**不拒绝零假设**。

### 8. 结论：

在 0.05 的显著性水平下，没有足够的证据表明这颗骰子是不均匀的。

## 考察色盲与性别之间是否独立 (卡方独立性检验) 🚻

此问题调查色盲与性别之间是否独立，基于对1000名高中生的调查数据，显著性水平为 α=0.05。

### 1. 假设：

- **零假设 (H0​)**: 色盲与性别相互独立。
- **备择假设 (H1​)**: 色盲与性别不独立 (即，它们之间存在关联)。

### 2. 观测频数：

|   |   |   |   |
|---|---|---|---|
|**性别 (Gender)**|**视觉 (Vision) - 正常 (Normal)**|**视觉 (Vision) - 色盲 (Colorblind)**|**合计 (Total)**|
|男 (Male)|535|65|600|
|女 (Female)|382|18|400|
|**合计 (Total)**|**917**|**83**|**1000**|

### 3. 期望频数 (Eij​):

单元格期望频数的计算公式为： Eij​=总计(第 i 行总计)×(第 j 列总计)​

- E男, 正常​=(600×917)/1000=550.2
- E男, 色盲​=(600×83)/1000=49.8
- E女, 正常​=(400×917)/1000=366.8
- E女, 色盲​=(400×83)/1000=33.2

### 4. 计算卡方检验统计量 (χ2)：

χ2=∑Eij​(Oij​−Eij​)2​

|   |   |   |   |   |   |
|---|---|---|---|---|---|
|**类别**|**观测频数 (Oij​)**|**期望频数 (Eij​)**|**(Oij​−Eij​)**|**(Oij​−Eij​)2**|**(Oij​−Eij​)2/Eij​**|

|男, 色盲|65|49.8|15.2|231.04|4.6393|

|女, 色盲|18|33.2|-15.2|231.04|6.9590|
|**合计**|||||**χ2≈12.648**|

### 5. 自由度 (df)：

df=(行数−1)×(列数−1)

df=(2−1)×(2−1)=1×1=1。

### 6. 临界值：

对于 α=0.05 和 df=1，临界卡方值 (χ0.05,12​) 为 3.841。

### 7. 决策：

在 0.05 的显著性水平下，有足够的证据表明色盲与性别之间不独立；即性别与色盲之间存在关联。

## 单因素方差分析 (One-Way ANOVA) 📊

此问题涉及完成一个方差分析表，并在显著性水平 α=0.05 下检验因子A是否有显著影响。因子A有三个水平，每个水平各做4次重复试验。

**已知信息：**

- 因子A的平方和 (SSA​) = 4.2
- 误差的平方和 (SSE​) = 2.5
- 总平方和 (SST​) = 6.7

### 1. 假设：

- **零假设 (H0​)**: 各组（因子A的各水平）的均值相等 (μ1​=μ2​=μ3​)。因子A没有显著影响。
- **备择假设 (H1​)**: 至少有一组的均值与其他组不同。因子A有显著影响。

### 2. 完成方差分析表：

- **自由度 (df):**
    
    - dfA​ (因子A) = k−1，其中 k 是水平数。 k=3。 dfA​=3−1=2。
    - dfE​ (误差) = N−k，其中 N 是总观测次数。3个水平各有4次重复，所以 N=3×4=12。 dfE​=12−3=9。
    - dfT​ (总计) = N−1=12−1=11。 (验证: dfA​+dfE​=2+9=11=dfT​)
- **均方和 (MS):**
    
    - MSA​=SSA​/dfA​=4.2/2=2.1。
    - MSE​=SSE​/dfE​=2.5/9≈0.2778。
- **F 比 (F):**
    
    - F=MSA​/MSE​=2.1/0.2778≈7.559。

**完成的方差分析表：**

|   |   |   |   |   |
|---|---|---|---|---|
|**来源 (Source)**|**平方和 (SS)**|**自由度 (df)**|**均方和 (MS)**|**F比 (F)**|
|因子A (Factor A)|4.2|2|2.1|7.559|
|误差e (Error e)|2.5|9|0.2778||
|总计 (Total)|6.7|11|||

### 3. 临界值：

对于 α=0.05，分子自由度 dfA​=2，分母自由度 dfE​=9，从F分布表中查得的临界F值 (F0.05,2,9​) 为 4.26。

### 4. 决策：

由于计算得到的 F 比 (7.559) 大于临界 F 值 (4.26)，我们**拒绝零假设**。

### 5. 结论：

在 0.05 的显著性水平下，有足够的证据表明因子A具有显著影响。
